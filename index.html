    Vue 入門課本

    給完全沒寫過程式的人。先學網頁的三個基本功：HTML、CSS、JavaScript，再學 Vue，最後自己做出一個小記帳網頁。

    HTML 範例旁邊會直接顯示畫面，按「改改看」就能自己改程式碼、馬上看到結果。

    怎麼念

    1. 一次念一節就好，不用一口氣念完一章。
    2. 看到程式碼，先猜結果，再看下面的畫面或輸出。
    3. 每個 HTML 範例都按「改改看」動手改一點，改壞了按「還原」。
    4. 每節最後有 1～2 題隨堂練習，念完那一節馬上做，確認有沒有讀懂。
    5. 念完一章再做章末練習（隨堂練習的題目也在裡面）。答錯時，解析下面有連結可以回到對應的小節。
    6. 做題進度存在這個瀏覽器，換裝置不會跟著走。

      這一章還不教程式，只做準備。念完你會：知道網頁是由哪幾種東西組成的、裝好寫網頁要用的兩個軟體、自己做出第一個網頁檔並用瀏覽器打開，還會打開瀏覽器內建的「開發者工具」。後面每一章都會用到這一章的步驟。

      0.1 網頁是由什麼組成的

      你每天在瀏覽器（Chrome、Edge、Safari）裡看到的網頁，其實都是一份份文字檔。瀏覽器讀這些文字，照裡面寫的內容把畫面畫出來。

      這些文字分成三種，各管一件事：

      名稱管什麼比喻（蓋房子）本書哪裡教
      HTML網頁上有什麼：標題、文字、圖片、按鈕房子的骨架和隔間第 1 章
      CSS東西長什麼樣：顏色、大小、位置油漆和裝潢第 2 章
      JavaScript東西會做什麼：按下按鈕後發生什麼事水電，讓燈會亮、門鈴會響第 3～7 章

      Vue 不是第四種語言。它是用 JavaScript 寫好的一套工具，讓你寫「會動的網頁」時輕鬆很多。所以要先學會前面三種，才學得懂 Vue。第 8 章開始才會用到 Vue。

      重點

      一般的網頁，HTML 一定要有，CSS 和 JavaScript 可以沒有。只有 HTML 的網頁也能看，只是樣子很陽春、不會動。

      這本書的範例怎麼看

      書裡的 HTML 範例會像下面這樣：上半部是程式碼，下半部的「畫面」是瀏覽器照這段程式碼畫出來的結果。

      第一個範例
      <h1>你好</h1>
<p>這是我的第一個網頁。</p>
      畫面

      現在還不用看懂程式碼。先試一下右上角的「改改看」按鈕：

      1. 按「改改看」，程式碼的框會出現虛線，表示可以打字了。
      2. 把 你好 改成你的名字。
      3. 看下面的「畫面」，大約半秒後就會跟著變。
      4. 改壞了也沒關係，按「還原」就會回到原本的樣子。

      你在書裡改的東西不會被存起來，重新整理頁面就會回到原樣。要留下來的作品，要照 0.3 節的方法存成自己的檔案。

      0.2 安裝兩個軟體：瀏覽器和 VS Code

      寫網頁只需要兩個軟體：

      軟體做什麼比喻
      瀏覽器打開網頁檔，把畫面畫出來；也用來找錯電視機
      VS Code打程式碼、存檔的文字編輯器紙和筆

      瀏覽器

      本書用 Google Chrome 說明。Windows 內建的 Edge 和 Chrome 是同一個核心做的，畫面和按鍵幾乎一樣，用 Edge 也可以。Mac 內建的 Safari 也能看網頁，但 0.5 節的開發者工具要另外打開設定，所以建議另外裝 Chrome。

      1. 到 Chrome 下載頁，按「下載 Chrome」。
      2. Mac：打開下載的 googlechrome.dmg，把 Chrome 圖示拖到「應用程式」資料夾。
      3. Windows：雙擊下載的安裝檔，等它自己裝完。

      VS Code

      VS Code（Visual Studio Code）是微軟出的免費編輯器，現在寫網頁的人大多用它。它會幫程式碼上色、自動補字，比電腦內建的記事本好用很多。

      1. 到 VS Code 官網，按下載按鈕。網站會自動選你的作業系統。
      2. Mac：下載的是一個 .zip，雙擊解開後會出現 Visual Studio Code 圖示，把它拖到「應用程式」資料夾。
      3. Windows：雙擊下載的安裝檔，選「我同意」，其他一路按「下一步」到裝完。

      VS Code 一開始是英文介面。想換成中文：打開 VS Code，按左邊一排圖示裡的「方塊」圖示（Extensions，擴充功能），搜尋 Chinese (Traditional)，安裝第一個結果，再照右下角的提示重新啟動。不換也完全不影響學習，本書提到選單時會中英文都寫。

      陷阱

      不要用 Mac 的「文字編輯」（TextEdit）或 Word 寫網頁。它們存檔時會偷偷加上排版資料，瀏覽器讀到的就不是你打的那些字了。Windows 的「記事本」雖然可以用，但很容易存成 .txt（下一節會講），也沒有上色和自動補字。

      0.3 做出第一個網頁檔

      第一步：建一個資料夾

      先在電腦上建一個資料夾，之後的練習都放在這裡。例如在「文件」裡建一個叫 vue-book 的資料夾。

      資料夾和檔案名稱建議只用英文小寫、數字和 -，不要用中文和空白。現在用中文還不會出問題，但第 15 章開始用的工具，遇到中文或空白的路徑偶爾會出錯，從一開始就養成習慣比較省事。

      第二步：用 VS Code 打開這個資料夾

      1. 打開 VS Code，選上方選單 File → Open Folder…（檔案 → 開啟資料夾），選剛剛的 vue-book。
      2. 如果跳出「Do you trust the authors…」（是否信任這個資料夾的作者），按 Yes, I trust the authors。這是你自己建的資料夾，可以信任。
      3. 左邊會出現檔案總管，最上面寫著 VUE-BOOK。

      第三步：新增檔案 index.html

      1. 把滑鼠移到左邊的 VUE-BOOK 上，會出現幾個小圖示，按第一個「New File…」（新增檔案）。
      2. 輸入檔名 index.html，按 Enter。右邊會打開這個空白檔案。
      3. 在檔案裡打一個驚嘆號 !，等一下會跳出提示選單，按 Enter（或 Tab）。

      VS Code 會自動幫你填好一整份網頁的基本架構，叫做「樣板」：

      HTML
      <!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Document</title>
</head>
<body>

</body>
</html>

      每一行是什麼意思，第 1 章 1.2 節會一行一行講。現在只要知道：要顯示在網頁上的東西，寫在 <body> 和 </body> 中間。

      把游標移到 <body> 下面那個空行，打上：

      HTML
      <h1>我的第一個網頁</h1>
<p>今天開始學寫網頁。</p>

      然後存檔：Mac 按 Cmd＋S，Windows 按 Ctrl＋S。

      陷阱

      沒存檔的檔案，VS Code 上方的檔名標籤旁邊會有一個白色圓點，存好之後圓點會變回 ×。瀏覽器讀的是存在硬碟裡的檔案，沒存檔的話，你打的字瀏覽器根本看不到。初學者最常見的「我改了怎麼沒變」，九成是忘了存檔。

      第四步：用瀏覽器打開

      到資料夾裡找到 index.html，雙擊它，電腦會用預設的瀏覽器打開。也可以直接把檔案拖進瀏覽器視窗。

      打開後看瀏覽器上方的網址列，會看到類似這樣的網址，表示瀏覽器讀的是你電腦裡的檔案，不是網路上的：

      file:///Users/你的名字/Documents/vue-book/index.html          ← Mac
file:///C:/Users/你的名字/Documents/vue-book/index.html       ← Windows

      Windows 的副檔名陷阱

      檔名最後面的 .html 叫副檔名，電腦靠它判斷這是什麼檔。Windows 預設會把副檔名藏起來，所以你看到的檔名 index.html 可能其實是 index.html.txt，瀏覽器就會把它當成純文字，直接把你打的程式碼原封不動顯示出來。

      用 VS Code 建檔通常不會發生這種事，但用其他方式建檔就很常見。建議先讓 Windows 把副檔名顯示出來：

      • Windows 11：打開檔案總管，按上方的「檢視」→「顯示」→ 勾選「副檔名」。
      • Windows 10：打開檔案總管，按上方的「檢視」分頁，勾選「副檔名」。

      Mac 的 Finder 也可能隱藏副檔名。要顯示的話：Finder 上方選單「Finder → 設定 → 進階」，勾選顯示副檔名的那一項（英文介面寫 Show all filename extensions）。

      重點

      打開網頁卻看到一整片程式碼（連 <h1> 都顯示出來），先檢查副檔名是不是 .html。

      0.4 改程式的循環：改 → 存 → 重新整理

      寫網頁的日常，就是一直重複這三步：

      1. 改在 VS Code 改程式碼
      2. 存Mac 按 Cmd＋S，Windows 按 Ctrl＋S
      3. 重新整理回到瀏覽器，Mac 按 Cmd＋R，Windows 按 F5 或 Ctrl＋R

      瀏覽器只在「打開」或「重新整理」的那一刻讀檔案。之後你再怎麼改檔案、存檔，瀏覽器畫面都不會自己變，要按重新整理它才會重讀一次。

      動手試一次：把 index.html 裡的「我的第一個網頁」改成「我的網頁」→ 存檔 → 回瀏覽器重新整理，確認標題變了。

      你做了什麼瀏覽器畫面會變嗎為什麼
      改了，沒存檔，按重新整理不會硬碟裡的檔案還是舊的
      改了，存檔，沒按重新整理不會瀏覽器還沒重新讀檔
      改了，存檔，按重新整理會三步都做了

      覺得每次都要按存檔很麻煩，可以打開 VS Code 的自動存檔：選單 File → Auto Save（檔案 → 自動儲存），前面出現勾勾就表示開了。開了以後只剩「改」和「重新整理」兩步。

      重點

      第 15 章會用到一套工具，存檔後瀏覽器會自己更新，連重新整理都不用按。在那之前，記住「改 → 存 → 重新整理」。

      試試 Elements

      打開你的 index.html，再打開開發者工具，點 Elements。你會看到剛才打的 <h1> 和 <p>。把滑鼠移到 <h1> 那一行，網頁上的標題會被藍色框起來，告訴你這一行對應畫面上的哪一塊。

      你也可以在 Elements 裡雙擊文字直接改，畫面會馬上變。但這只是暫時改了瀏覽器裡的那一份，不會改到你的檔案，重新整理就沒了。它適合用來「先試試看」，確定要改了，還是要回 VS Code 改檔案。

      試試 Console

      點 Console，在最下面有 > 符號的那一行打：

      1 + 1

      按 Enter，下一行會出現 2。你剛剛執行了第一行 JavaScript。Console 會把你打的東西當成 JavaScript 執行，再把結果顯示出來。第 3 章會常常在這裡做實驗。

      陷阱

      如果你是貼上程式碼，而不是自己打字，Chrome 可能會跳出警告，要你先打 allow pasting 才能貼。這是 Chrome 的防詐騙設計：壞人常叫別人把一段程式碼貼進 Console 來偷資料。來源不明的程式碼，不要貼進 Console。

      重點

      程式跑不出預期的結果時，第一件事就是打開開發者工具看 Console 有沒有紅字。紅字就是錯誤訊息，會告訴你錯在哪一行。

      • 網頁由三種文字組成：HTML 管有什麼、CSS 管長什麼樣、JavaScript 管會做什麼。Vue 是用 JavaScript 寫成的工具，第 8 章才用到。
      • 寫網頁要兩個軟體：瀏覽器（Chrome 或 Edge）和 VS Code。不要用文字編輯（TextEdit）或 Word。
      • 網頁檔的副檔名是 .html。Windows 預設會藏副檔名，小心存成 .html.txt。
      • 在 VS Code 的 .html 檔裡打 ! 再按 Enter，會自動產生網頁樣板。要顯示的內容寫在 <body> 裡。

      這一章學 HTML，也就是網頁的骨架。念完你會：看懂一個標籤由哪幾個部分組成、知道一份網頁檔的基本架構每一行在做什麼、會放標題、段落、連結、圖片、清單、表格和輸入框，最後學會用 div、class、id 把網頁分區。這些都是之後寫 Vue 畫面的基本材料。

      1.1 標籤：HTML 的基本單位

      HTML 用標籤（tag）告訴瀏覽器「這段文字是什麼東西」。例如這是一個大標題、那是一段文字。看一個最簡單的例子：

      HTML
      <h1>今天的記帳</h1>
<p>早餐花了 60 元。</p>
      畫面

      拆開第一行看，它由三個部分組成：

      部分寫法意思
      開始標籤<h1>告訴瀏覽器：「大標題從這裡開始」
      內容今天的記帳要顯示的文字
      結束標籤</h1>告訴瀏覽器：「大標題到這裡結束」。和開始標籤一樣，只是多了一條斜線 /

      開始標籤、內容、結束標籤合起來，叫做一個元素（element）。所以上面的例子有兩個元素：一個 h1 元素、一個 p 元素。

      重點

      標籤是用尖括號 < > 包起來的名稱。結束標籤在名稱前面多一條斜線 /。標籤本身不會顯示在畫面上，顯示的只有內容。

      標題與段落

      h 是 heading（標題）的縮寫。HTML 有 h1 到 h6 六級標題，h1 最大、最重要，h6 最小。p 是 paragraph（段落）的縮寫，用來放一般的文字。

      六級標題和段落
      <h1>h1 大標題</h1>
<h2>h2 第二級</h2>
<h3>h3 第三級</h3>
<h6>h6 最小的標題</h6>
<p>這是一個段落。</p>
<p>這是另一個段落，兩個段落之間會自動空一點距離。</p>
      畫面

      標題要照順序用：大標題用 h1，底下的小節用 h2，再下一層用 h3。不要因為「想要字小一點」就跳去用 h4。字的大小是外觀，第 2 章會用 CSS 調整。HTML 只負責說「這是第幾級標題」。

      陷阱

      結束標籤的斜線很容易漏打。寫成 <h1>標題<h1> 的話，瀏覽器會以為第二個 <h1> 是另一個標題的開始，後面的文字全部被當成大標題。畫面突然出現一大片粗大的字，先檢查結束標籤有沒有斜線。

      1.2 一份網頁檔的基本架構

      第 0 章在 VS Code 打 ! 產生的樣板，每一行都有作用。現在一行一行看：

      HTML
      <!DOCTYPE html>
<html lang="zh-Hant">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>我的記帳本</title>
</head>
<body>
    <h1>今天的記帳</h1>
</body>
</html>
      這一行做什麼
      <!DOCTYPE html>告訴瀏覽器：「這是一份用現代 HTML 寫的網頁」。永遠放在第一行，照抄就好
      <html lang="zh-Hant">整份網頁的最外層。lang 說明網頁用什麼語言，zh-Hant 是繁體中文。樣板預設的 en 是英文，改成中文比較正確
      <head> … </head>網頁的「頭」：放給瀏覽器看的設定，不會顯示在頁面內容裡
      <meta charset="UTF-8">告訴瀏覽器這份檔案用 UTF-8 編碼。少了它，中文可能變成亂碼
      <meta name="viewport" …>讓網頁在手機上用正確的寬度顯示。少了它，手機會把網頁縮得很小
      <title> … </title>網頁的名稱，顯示在瀏覽器分頁標籤上，不是顯示在頁面裡
      <body> … </body>網頁的「身體」：所有要顯示給人看的內容都寫在這裡

      <!DOCTYPE html> 和 <meta charset>、<meta name="viewport"> 這種寫一次就不用管的設定，每份網頁都長得一樣，用 VS Code 的 ! 產生就好，不用背。真正要每天寫的只有 <body> 裡面。

      陷阱

      <title> 不是頁面上的大標題。它只出現在瀏覽器分頁標籤上，還有加入書籤時的名稱。頁面上的大標題要用 <h1>。

      為什麼要 meta charset

      電腦存文字時，要把每個字轉成數字存起來，轉換的規則叫編碼。VS Code 預設用 UTF-8 這套規則存檔。瀏覽器讀檔時，如果沒有人告訴它檔案是用哪套規則存的，它只能用猜的，猜錯就會把中文顯示成「ä»Šå¤©」這種亂碼。<meta charset="UTF-8"> 就是直接告訴瀏覽器答案，不讓它猜。

      重點

      書裡的 HTML 範例為了簡短，只寫 <body> 裡面的內容。你自己存成檔案時，一定要放進完整的樣板裡。

      1.3 元素裡面放元素，以及空白和換行

      巢狀

      元素裡面可以再放元素，叫做巢狀（nesting）。例如在段落裡，想把某幾個字變粗體強調，可以用 <strong>：

      HTML
      <p>早餐花了 <strong>60 元</strong>，有點貴。</p>
      畫面

      strong 元素整個被包在 p 元素裡面。這時我們說 p 是 strong 的父元素（parent），strong 是 p 的子元素（child）。前面的 <html> 包著 <head> 和 <body>，也是同樣的關係。

      巢狀有一個規則：先開的後關。像收納盒一樣，小盒子要整個放進大盒子裡，不能一半在裡面一半在外面。

      寫法對不對原因
      <p>花了 <strong>60 元</strong></p>對strong 先關，p 後關，strong 整個在 p 裡面
      <p>花了 <strong>60 元</p></strong>錯p 先關了，strong 卻還沒關，兩個盒子交叉了

      寫錯的話，瀏覽器不會跳出錯誤訊息，而是自己猜你想怎樣、自動修正，畫出來的結果常常跟你想的不一樣。HTML 寫錯不會報錯，所以畫面怪怪的時候，要打開開發者工具的 Elements，看瀏覽器實際修成什麼樣子。

      縮排

      裡層的元素通常會往右縮排，讓人一眼看出誰包著誰。縮排只是給人看的，瀏覽器不在乎。下面兩種寫法，畫出來完全一樣：

      HTML
      <body><h1>記帳</h1><p>早餐 60 元</p></body>

<body>
    <h1>記帳</h1>
    <p>早餐 60 元</p>
</body>

      第二種好讀很多，所以大家都這樣寫。VS Code 裡選取幾行後按 Tab 會往右縮，按 Shift＋Tab 往左縮。

      空白和換行會被合併

      這是初學者最常嚇一跳的地方：你在程式碼裡按的 Enter 和連續空白，瀏覽器都不會照樣顯示。連續的空白、換行，全部被當成一個空白。

      在程式碼裡換行和空很多格
      <p>早餐 60 元
午餐 120 元
晚餐     200 元</p>
      畫面

      三行字被接成一行，「晚餐」後面的五個空白也只剩一個。想要換行有兩種做法：

      • 分成不同段落：每一筆寫成一個 <p>。這是比較好的做法，因為它們本來就是不同的東西。
      • 用 <br> 強制換行：br 是 break（斷開）的縮寫。它只是在原地換行，適合地址、詩句這種「同一段文字但要分行」的情況。
      用 br 換行
      <p>早餐 60 元<br>午餐 120 元<br>晚餐 200 元</p>
      畫面

      注意 <br> 沒有結束標籤，因為它裡面不會放任何內容。這種元素叫空元素（void element），下一節的 <img> 也是。

      重點

      程式碼裡的換行和連續空白，在畫面上只算一個空白。要分段用 <p>，要在同一段裡換行用 <br>。

      1.4 屬性：連結和圖片

      HTML

      畫面

      清單

      第 12 章 Vue 的 v-model，就是把這些輸入框和資料綁在一起：使用者一打字，資料就跟著變。

      前面的元素都有特定意思：h1 是標題、p 是段落、li 是清單項目。但有時候你只是想把幾個東西「包成一組」，好讓 CSS 一起調整樣式，或讓 JavaScript 一起處理。這時用兩個本身沒有意思的元素：

      spanspan（一小段）包住一行文字裡的一小段，例如金額數字。不會換行

    <p>金額：<span>120</span> 元</p>
</div>

      網頁上有很多 div，CSS 和 JavaScript 要怎麼指定「是哪一個」？方法是替元素加上 class 或 id 屬性：

      HTML

      1.8 註解，以及用開發者工具看 HTML

      註解

      寫在 <!-- 和 --> 中間的文字叫註解（comment）。瀏覽器會完全忽略它，畫面上不會顯示。用來替自己或同事寫說明，或者暫時把一段程式碼「關掉」又不想刪掉：

      HTML

<p>晚餐 200 元</p>

      畫面上只有早餐和晚餐，午餐那一行被註解包住，瀏覽器就不畫了。在 VS Code 裡選取幾行，按 Cmd＋/（Windows 是 Ctrl＋/）可以一次加上或拿掉註解。

      陷阱

      註解不會顯示在畫面上，但任何人都看得到。在網頁上按右鍵選「檢視網頁原始碼」，註解就在裡面。密碼、內部資訊絕對不要寫在 HTML 註解裡。

      用 Elements 看結構

      第 0 章打開過開發者工具的 Elements 分頁。現在你看得懂裡面的東西了：它顯示的就是網頁的元素，用縮排和三角形箭頭表示誰包著誰。點三角形可以展開或收起子元素。

      重點

      畫面不如預期時，用 Elements 的箭頭工具點那個地方，看瀏覽器實際看到的結構。

      1.9 本章整理

      • 元素 ＝ 開始標籤 ＋ 內容 ＋ 結束標籤。結束標籤多一條斜線，例如 <p>…</p>。
      • 網頁樣板：<head> 放設定（meta charset 防亂碼、title 是分頁標籤上的名稱），<body> 放要顯示的內容。
      • 標題 h1～h6 照層級用，段落用 p，強調用 strong。
      • 巢狀要「先開的後關」，不能交叉。HTML 寫錯不會報錯，瀏覽器會自己猜，要用 Elements 檢查。
      • 程式碼裡的換行和連續空白只算一個空白。分段用 p，同一段換行用 br。
      • 屬性寫在開始標籤裡：名稱="值"，多個屬性用空白隔開。連結 <a href>、圖片 <img src alt>。
      • 相對網址從目前 HTML 檔所在的資料夾開始找，檔名用小寫最保險。
      • 沒有內容的空元素沒有結束標籤：br、img、input。
      • 清單：ul（圓點）、ol（編號），每項都是 li。表格：table 裡一列一個 tr，格子用 th（標題）或 td（資料）。
      • 表單元素：input 換 type 就變不同的框（text、number、checkbox），下拉選單 select＋option，按鈕 button。label 的 for 對上輸入框的 id。
      • 布林屬性（如 checked）只看有沒有寫，不看值。
      • div 包一大塊、span 包一小段，本身沒有樣式。id 全頁唯一，class 可以重複、一個元素可以有好幾個。
      • 註解 <!-- --> 不會顯示，但任何人都看得到原始碼。

      這一章學 CSS，負責網頁的外觀。念完你會：知道 CSS 寫在哪裡、看懂一條規則的每個部分、用選擇器指定要改哪些元素、知道兩條規則打架時誰會贏、會調顏色和文字，最後學會「盒子模型」和用 Flexbox 把東西排成一排。這些就足夠把第 18 章的記帳網頁排得整整齊齊。

      2.1 CSS 寫在哪裡

      CSS 是 Cascading Style Sheets（層疊樣式表）的縮寫。它是另一種語言，專門描述「HTML 元素長什麼樣子」。CSS 有三種寫法：

      寫法一：寫在 style 元素裡（本書範例最常用）

      HTML
      <style>
    h1 {
        color: green;
    }
</style>
<h1>今天的記帳</h1>
<p>早餐 60 元</p>
      畫面

      <style> 和 </style> 中間寫的就是 CSS，不是 HTML。上面那條的意思是：「所有 h1 的文字顏色都改成綠色」。p 沒有被指定，所以還是黑色。

      在完整的網頁檔裡，<style> 要放在 <head> 裡面，因為它是「設定」，不是要顯示的內容。書裡的範例為了簡短，直接放在最前面，畫出來的效果一樣。

      寫法二：寫在另一個 .css 檔，用 link 引進來

      網站有很多頁時，把 CSS 統一寫在一個 .css 檔，每一頁用 <link> 引進來，改一個檔就能改全部頁面：

      HTML
      <!-- index.html 的 head 裡 -->
<link rel="stylesheet" href="style.css">
      CSS
      /* style.css：這個檔裡只寫 CSS，不用寫 <style> */
h1 {
    color: green;
}

      rel="stylesheet" 說明「這是樣式表」，href 是 .css 檔的位置，用的是第 1 章學過的相對網址。

      寫法三：寫在元素的 style 屬性裡

      HTML
      <h1 style="color: green;">今天的記帳</h1>

      這樣只會影響這一個元素。寫起來快，但東西一多就很難管理，因為樣式散落在各個元素上，要改得一個一個找。只在臨時測試，或第 10 章 Vue 用資料動態改樣式時才會用到。

      重點

      初學時把 CSS 寫在 <style> 裡最方便。網站變大以後改成獨立的 .css 檔。style 屬性盡量少用。

      2.2 一條 CSS 規則的寫法

      CSS 是由一條一條規則（rule）組成的。拆開下面這條看：

      CSS
      p {
    color: red;
    font-size: 20px;
}
      部分寫法意思
      選擇器（selector）p要改哪些元素。這裡是所有的 p
      大括號{ … }包住這條規則的所有設定
      屬性（property）color、font-size要改什麼：文字顏色、文字大小
      冒號:分隔屬性和值
      值（value）red、20px要改成什麼
      分號;一個設定結束。每個設定後面都要加

      屬性: 值; 這一組叫一個宣告（declaration）。一條規則裡可以有很多個宣告，習慣上一行寫一個。

      注意 CSS 的「屬性」和 HTML 的「屬性」雖然中文一樣，是兩回事：HTML 的屬性寫在標籤裡（href="…"），CSS 的屬性寫在大括號裡（color: red）。

      寫錯時會怎樣

      CSS 跟 HTML 一樣，寫錯不會出現錯誤訊息。瀏覽器會跳過看不懂的那個宣告，其他的照常套用。最常見的錯有兩種：

      漏了分號
      <style>
    p {
        color: red
        font-size: 30px;
    }
</style>
<p>早餐 60 元</p>
      畫面

      color: red 後面少了分號，瀏覽器就讀成一個很長的值「red font-size: 30px」。這不是合法的顏色，於是整個宣告被丟掉，連下一行的 font-size 也一起失效。所以字還是黑色、大小也沒變。按「改改看」把分號補上，兩個設定都會生效。

      打成全形冒號
      <style>
    p {
        color：red;
        font-size: 30px;
    }
</style>
<p>早餐 60 元</p>
      畫面

      color：red 用的是中文輸入法打出來的全形冒號 ：，瀏覽器不認得，這個宣告被跳過。但它後面有分號，所以下一行的 font-size 不受影響，字還是變大了。

      陷阱

      寫程式時要切換成英文輸入法。中文輸入法打出的全形 ：；｛｝＂，看起來和半形的 :;{}" 很像，但電腦完全當成不同的字。在 VS Code 裡，看不懂的 CSS 底下通常會出現波浪線，可以幫你找到這種錯。

      2.3 選擇器：指定要改哪些元素

      選擇器決定「這條規則套用到誰身上」。最常用的有下面幾種：

      種類寫法選到誰
      標籤選擇器p所有 p 元素
      class 選擇器.money所有 class 裡有 money 的元素。前面加一個點
      id 選擇器#totalid 是 total 的那一個元素。前面加一個井字號
      後代選擇器.card span在 .card 裡面的所有 span。兩個選擇器中間用空白隔開
      群組h1, h2h1 和 h2 都套用。用逗號隔開
      各種選擇器
      <style>
    .money {
        color: red;
    }
    #total {
        font-weight: bold;
    }
    .card span {
        background-color: yellow;
    }
</style>
<div class="card">
    <p>早餐 <span class="money">60</span> 元</p>
    <p>午餐 <span>120</span> 元</p>
</div>
<p>外面的 <span>span</span> 不受 .card span 影響</p>
<p id="total">合計 <span class="money">180</span> 元</p>
      畫面

      對照畫面一條一條看：

      • .money：「60」和「180」都是紅字，因為它們都有 class="money"。一條規則同時套到兩個元素上，這就是 class 好用的地方。
      • #total：只有「合計」那一行變粗。
      • .card span：「60」和「120」有黃底，因為它們在 class="card" 的 div 裡面。第三行的 span 在 .card 外面，所以沒有黃底。「180」也在外面，所以只有紅字、沒有黃底。
      陷阱

      選擇器裡的點和井字號只在 CSS 裡寫，HTML 裡不寫。HTML 寫 class="money"，CSS 寫 .money。寫成 class=".money" 的話，CSS 的 .money 就選不到它。

      陷阱

      後代選擇器中間的空白很重要。.card span 是「.card 裡面的 span」；.card, span 多了一個逗號，意思就變成「.card 和所有 span」，差很多。

      2.4 兩條規則打架時，誰會贏

      同一個元素常常同時被好幾條規則選到。如果它們設定了同一個屬性，例如都設了 color，只會有一個生效。瀏覽器照下面的順序決定誰贏：

      規則一：選擇器越「具體」越強

      選擇器指得越精準，分量越重：

      1. 標籤p：所有段落，最籠統
      2. class.money：某一類元素
      3. id#total：唯一的那一個，最具體
      HTML
      <style>
    #total {
        color: green;
    }
    .money {
        color: red;
    }
    p {
        color: blue;
    }
</style>
<p>一般段落</p>
<p class="money">有 class 的段落</p>
<p id="total" class="money">有 id 也有 class 的段落</p>
      畫面
      段落被哪些規則選到誰贏結果
      第一段p只有一條藍
      第二段p、.moneyclass 比標籤具體紅
      第三段p、.money、#totalid 最具體綠

      注意 #total 明明寫在最前面，還是贏了。具體程度比寫的順序重要。

      規則二：一樣具體時，後寫的贏

      HTML
      <style>
    .money {
        color: red;
    }
    .highlight {
        color: orange;
    }
</style>
<p class="money highlight">60 元</p>
      畫面

      兩條都是 class 選擇器，一樣具體，所以看誰寫在後面：.highlight 在後，字是橘色。注意，這裡看的是 CSS 裡規則的順序，跟 HTML 裡 class="money highlight" 兩個名字的順序無關。按「改改看」把 HTML 改成 class="highlight money"，顏色不會變；把 CSS 兩條規則上下對調，才會變成紅色。

      規則三：style 屬性比所有選擇器都強

      直接寫在元素上的 style="…"，會贏過 <style> 裡的任何選擇器，連 id 也贏不了它。這也是 2.1 節說盡量少用的原因之一：它太強了，之後想用 CSS 蓋過去很麻煩。

      繼承：沒設定的，有些會跟爸爸一樣

      有些屬性，父元素設了，子元素沒設的話，會自動跟著父元素，叫做繼承。文字相關的屬性大多會繼承，盒子相關的大多不會：

      HTML
      <style>
    .card {
        color: purple;
        border: 2px solid gray;
    }
</style>
<div class="card">
    <p>早餐 <strong>60</strong> 元</p>
</div>
      畫面

      div 設了紫色字，裡面的 p 和 strong 都沒設顏色，所以都繼承成紫色。但 border（邊框，2.6 節會講）不會繼承，所以只有外面的 div 有框，p 自己沒有框。如果邊框會繼承，每一層都會多一個框，那就太亂了。

      會繼承（文字類）不會繼承（盒子類）
      color、font-size、font-weight、text-alignborder、padding、margin、width、background-color

      background-color 不會繼承，但子元素的背景預設是透明的，所以看起來會「透出」父元素的底色。這不是繼承，是透明。

      重點

      誰贏的判斷順序：style 屬性 ＞ id ＞ class ＞ 標籤；一樣具體時後寫的贏。自己完全沒被任何規則設定到的屬性，才會去看繼承。

      2.5 顏色和文字

      顏色的寫法

      寫法例子說明
      英文名稱red、green、gray最好懂，但只有固定的一百多種
      十六進位#e53935# 後面六個字，每兩個一組，依序是紅、綠、藍的量（00 最少、ff 最多）。設計稿上的顏色大多用這種
      rgbrgb(229, 57, 53)紅、綠、藍各是 0～255。和上面的 #e53935 是同一個顏色

      顏色不用自己算。VS Code 在 CSS 的顏色值旁邊會顯示一個小色塊，點它就會跳出調色盤。

      常用的文字和顏色屬性

      HTML
      <style>
    .title {
        color: white;
        background-color: #2e7d32;
        font-size: 24px;
        text-align: center;
    }
    .money {
        font-weight: bold;
        font-size: 150%;
    }
</style>
<p class="title">本月支出</p>
<p>合計 <span class="money">3,280</span> 元</p>
      畫面
      屬性管什麼常用的值
      color文字顏色任何顏色
      background-color背景顏色任何顏色
      font-size文字大小16px、150%
      font-weight文字粗細normal（一般）、bold（粗）
      text-align文字在這一塊裡怎麼對齊left、center、right

      單位：px 和 %

      px 是 pixel（像素），螢幕上的一個小點，是最直接的單位。瀏覽器預設的文字大小是 16px。

      % 是「相對於某個東西的百分之幾」。在 font-size 裡，是相對於父元素的文字大小。上面的「3,280」在 p 裡面，p 是預設的 16px，所以 150% 就是 16 × 1.5 ＝ 24px。同樣是 150%，放在 20px 的父元素裡就會變成 30px。

      陷阱

      數字和單位之間不能有空白：16px 正確，16 px 會被當成看不懂的值而跳過。另外除了 0 以外，數字一定要帶單位：font-size: 16 沒有單位，也會被跳過。

      2.6 盒子模型：每個元素都是一個盒子

      在瀏覽器眼中，每個元素都是一個長方形的盒子。這個盒子由內到外有四層：

      層屬性比喻（裱框的畫）
      內容（content）width、height畫本身
      內距（padding）padding畫和框之間的白邊
      邊框（border）border畫框
      外距（margin）margin這幅畫和隔壁那幅畫之間的牆面空隙
      一張記帳卡片
      <style>
    .card {
        width: 200px;
        padding: 16px;
        border: 2px solid #2e7d32;
        margin: 12px;
        background-color: #e8f5e9;
    }
</style>
<div class="card">早餐 60 元</div>
<div class="card">午餐 120 元</div>
      畫面

      看畫面：淺綠色的背景會塗滿內容＋內距，然後是綠色的框，框外面的空隙是外距，所以兩張卡片之間隔開了。

      border 的寫法

      border: 2px solid #2e7d32; 一次寫了三件事，用空白隔開：

      部分意思其他常用的值
      2px框的粗細1px
      solid框的樣式：實線dashed（虛線）、dotted（點線）
      #2e7d32框的顏色任何顏色

      solid 這一項不能省略。只寫 border: 2px #2e7d32; 的話樣式預設是「沒有框」，什麼都看不到。

      padding 和 margin 的寫法

      padding: 16px; 是上下左右四邊都 16px。也可以分開設：

      寫法意思
      padding: 16px;四邊都是 16px
      padding: 8px 16px;上下 8px，左右 16px
      padding-top: 8px;只設上面。另外還有 -right、-bottom、-left

      margin 的寫法完全一樣。另外，margin: 0 auto; 是一個常見的技巧：上下 0、左右「自動平分剩下的空間」，可以讓一個有設寬度的盒子在畫面上水平置中。

      盒子到底多寬：box-sizing

      上面的卡片設了 width: 200px，但它在畫面上其實是 236px 寬。因為預設情況下，width 只管內容那一層，內距和邊框要另外加上去：

      左邊框 2 ＋ 左內距 16 ＋ 內容 200 ＋ 右內距 16 ＋ 右邊框 2 ＝ 236px

      （外距不算在盒子的寬度裡，它是盒子外面的空隙。）

      這很不直覺：想要一張 200px 的卡片，還得自己扣掉內距和邊框。所以現在幾乎所有網站都會在 CSS 最前面加上這一條，讓 width 改成包含內距和邊框：

      加上 box-sizing: border-box
      <style>
    * {
        box-sizing: border-box;
    }
    .card {
        width: 200px;
        padding: 16px;
        border: 2px solid #2e7d32;
        background-color: #e8f5e9;
    }
</style>
<div class="card">早餐 60 元</div>
      畫面

      * 是「所有元素」的選擇器。加了這條以後，卡片就是剛好 200px，內容區自動縮成 200 − 32 − 4 ＝ 164px。本書之後的範例，只要用到寬度，都會加上這條。

      重點

      盒子由內到外：內容 → 內距 padding → 邊框 border → 外距 margin。預設的 width 只算內容；加上 box-sizing: border-box 後，width 會包含內距和邊框。

      用 CSS 畫表格格線

      第 1 章用 border="1" 畫表格線。用 CSS 的正式做法是替每一格加邊框，再把相鄰的框合併成一條線：

      HTML
      <style>
    table {
        border-collapse: collapse;
    }
    th, td {
        border: 1px solid #999;
        padding: 4px 12px;
    }
</style>
<table>
    <tr><th>項目</th><th>金額</th></tr>
    <tr><td>早餐</td><td>60</td></tr>
    <tr><td>午餐</td><td>120</td></tr>
</table>
      畫面

      border-collapse: collapse 的意思是「相鄰格子的框合併」。按「改改看」把這一行刪掉，就會看到每一格各自有框、中間變成雙線。

      2.7 區塊元素和行內元素

      第 1 章說 div 會獨佔一行、span 不會。原因是每個元素都有一個預設的顯示方式（display）：

      區塊元素（block）行內元素（inline）
      例子div、p、h1～h6、ul、li、tablespan、a、strong、img
      排列方式獨佔一整行，下一個元素一定從下一行開始像文字一樣排在同一行，排滿了才換行
      寬度沒設的話，自動撐滿父元素的寬度跟著內容一樣寬
      能不能設 width、height可以不行，設了也沒用（img 例外）
      HTML
      <style>
    div, span {
        border: 1px solid #e53935;
        width: 120px;
    }
</style>
<div>div 一</div>
<div>div 二</div>
<span>span 一</span>
<span>span 二</span>
      畫面

      兩個 div 上下排，各佔一行，寬度照設定的 120px（加上框）。兩個 span 排在同一行，寬度只跟著文字，width: 120px 對它們完全沒有作用。

      用 display 改變顯示方式

      元素預設是哪一種，可以用 display 屬性改掉：

      寫法效果
      display: block;變成區塊元素。例如讓 a 連結獨佔一行、可以設寬高，做成大按鈕
      display: inline;變成行內元素。例如讓 li 排成一排
      display: inline-block;排在同一行，但可以設寬高，兩者的優點都有
      display: none;整個不顯示，也不佔空間，就像不存在一樣

      display: none 很重要，第 11 章 Vue 的 v-show 就是用它把東西藏起來的。下一節的 display: flex 則是現在排版的主力。

      2.8 Flexbox：把東西排成一排

      做網頁時最常遇到的排版需求：把幾個東西排成橫的一排，例如「項目在左邊、金額在右邊」。區塊元素會一個疊一個往下排，做不到這件事。這時用 Flexbox：在父元素加上 display: flex，它的子元素就會改成橫向排列。

      HTML
      <style>
    .row {
        display: flex;
        border: 1px solid #999;
    }
</style>
<div class="row">
    <div>早餐</div>
    <div>60 元</div>
</div>
      畫面

      兩個 div 本來會上下排，現在變成左右排了。注意 display: flex 是加在外面那一層（.row）身上，被影響的是它的子元素。

      接下來用幾個屬性調整子元素怎麼排。這些屬性也都寫在父元素上：

      記帳列表的一行
      <style>
    * {
        box-sizing: border-box;
    }
    .row {
        display: flex;
        justify-content: space-between;
        align-items: center;
        gap: 8px;
        padding: 8px 12px;
        border-bottom: 1px solid #ddd;
    }
    .money {
        font-size: 20px;
        font-weight: bold;
    }
</style>
<div class="row">
    <span>早餐</span>
    <span class="money">60</span>
</div>
<div class="row">
    <span>午餐</span>
    <span class="money">120</span>
</div>
      畫面
      屬性管什麼常用的值
      justify-content子元素在橫向怎麼分配flex-start（靠左，預設）、center（置中）、flex-end（靠右）、space-between（第一個靠最左、最後一個靠最右，剩下的空間平分在中間）
      align-items子元素在直向怎麼對齊stretch（拉成一樣高，預設）、center（垂直置中）
      gap子元素之間的間距8px
      flex-direction排列方向row（橫排，預設）、column（直排）

      上面的例子：space-between 讓項目靠左、金額靠右；align-items: center 讓字比較大的金額和項目垂直對齊在中間。按「改改看」，把 space-between 換成 center 或 flex-end，看看差別。

      讓某一個子元素佔滿剩下的空間

      在子元素上加 flex: 1，它就會撐開、吃掉剩下的所有空間。常用在「輸入框佔滿、按鈕在右邊」這種版面：

      HTML
      <style>
    .add {
        display: flex;
        gap: 8px;
    }
    .add input {
        flex: 1;
    }
</style>
<div class="add">
    <input placeholder="項目">
    <button>新增</button>
</div>

      陷阱

      初學者最常見的錯：把 display: flex 加在想要排成一排的那幾個元素自己身上。它要加在包住它們的父元素上。同樣地，justify-content、align-items、gap 也都寫在父元素上；只有 flex: 1 寫在子元素上。

      重點

      Flexbox 三步驟：①在父元素加 display: flex ②用 justify-content 調橫向、align-items 調直向 ③用 gap 調間距。

      2.9 用開發者工具看 CSS

      CSS 沒照你想的生效時，打開開發者工具的 Elements 分頁，點選那個元素，看右邊（或下面）的 Styles 面板。這裡會列出所有選到這個元素的規則：

      • 被劃掉的宣告：有被選到，但打架打輸了（2.4 節）。往上看，會有另一條規則設定了同一個屬性並且贏了它。
      • 被劃掉、旁邊還有黃色警告圖示的宣告：不是打輸，而是瀏覽器看不懂這個宣告，例如 16 px、全形冒號、拼錯字。把滑鼠移到圖示上會顯示原因。2.2 和 2.5 節的錯誤在這裡都看得到。
      • 完全沒出現你寫的規則：選擇器根本沒選到這個元素。檢查 class 名稱有沒有拼錯、點和井字號有沒有寫對。

      Styles 面板最下面（或 Computed 分頁裡）有一張盒子模型的圖，用不同顏色標出內容、內距、邊框、外距各是多少 px。2.6 節的寬度問題，看這張圖最清楚。

      在 Styles 面板裡可以直接點值來改、勾掉前面的勾勾暫時關掉某個宣告，畫面會馬上變。跟 Elements 改 HTML 一樣，這些改動不會存回你的檔案，試出想要的效果後，要回 VS Code 改。

      重點

      CSS 沒生效，照順序查：①Styles 裡有沒有出現這條規則（沒有＝選擇器沒選到）②有沒有黃色警告圖示（有＝宣告寫錯了）③有沒有被劃掉（只劃掉沒警告＝打輸了）。

      2.10 本章整理

      • CSS 三種寫法：<style> 元素（放在 head）、外部 .css 檔用 <link rel="stylesheet"> 引入、元素的 style 屬性（盡量少用）。
      • 規則 ＝ 選擇器 ＋ { 屬性: 值; }。寫錯不會報錯，看不懂的宣告會被跳過；漏了分號會連下一個宣告一起失效。不要用全形符號。
      • 選擇器：p（標籤）、.money（class）、#total（id）、.card span（.card 裡的 span）、h1, h2（群組）。點和井字號只寫在 CSS 裡。
      • 打架時：style 屬性 ＞ id ＞ class ＞ 標籤；一樣具體時，CSS 裡後寫的贏。文字類屬性會繼承，盒子類不會。
      • 顏色可以用英文名稱、#rrggbb、rgb()。font-size 的 % 相對於父元素的文字大小。數字和單位之間不能有空白。
      • 盒子模型由內到外：內容 → padding → border → margin。border 要寫樣式（如 solid）才看得到。加上 * { box-sizing: border-box; }，width 就包含內距和邊框。
      • 區塊元素獨佔一行、可設寬高；行內元素排在同一行、設寬高沒用。display 可以改，display: none 會整個不顯示。
      • Flexbox：父元素加 display: flex，子元素橫排。justify-content 調橫向、align-items 調直向、gap 調間距；子元素加 flex: 1 撐滿剩下的空間。
      • CSS 沒生效，用開發者工具的 Styles 面板查：沒出現、有黃色警告圖示、被劃掉。
