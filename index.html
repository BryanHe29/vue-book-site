    Vue 入門課本

    給完全沒寫過程式的人。先學網頁的三個基本功：HTML、CSS、JavaScript，再學 Vue，最後自己做出一個小記帳網頁。

    HTML 範例旁邊會直接顯示畫面，按「改改看」就能自己改程式碼、馬上看到結果。

    怎麼念

    1. 一次念一節就好，不用一口氣念完一章。
    2. 看到程式碼，先猜結果，再看下面的畫面或輸出。
    3. 每個 HTML 範例都按「改改看」動手改一點，改壞了按「還原」。
    4. 每節最後有 1～2 題隨堂練習，念完那一節馬上做，確認有沒有讀懂。
    5. 念完一章再做章末練習（隨堂練習的題目也在裡面）。答錯時，解析下面有連結可以回到對應的小節。
    6. 做題進度存在這個瀏覽器，換裝置不會跟著走。

      這一章還不教程式，只做準備。念完你會：知道網頁是由哪幾種東西組成的、裝好寫網頁要用的兩個軟體、自己做出第一個網頁檔並用瀏覽器打開，還會打開瀏覽器內建的「開發者工具」。後面每一章都會用到這一章的步驟。

      0.1 網頁是由什麼組成的

      你每天在瀏覽器（Chrome、Edge、Safari）裡看到的網頁，其實都是一份份文字檔。瀏覽器讀這些文字，照裡面寫的內容把畫面畫出來。

      這些文字分成三種，各管一件事：

      名稱管什麼比喻（蓋房子）本書哪裡教
      HTML網頁上有什麼：標題、文字、圖片、按鈕房子的骨架和隔間第 1 章
      CSS東西長什麼樣：顏色、大小、位置油漆和裝潢第 2 章
      JavaScript東西會做什麼：按下按鈕後發生什麼事水電，讓燈會亮、門鈴會響第 3～7 章

      Vue 不是第四種語言。它是用 JavaScript 寫好的一套工具，讓你寫「會動的網頁」時輕鬆很多。所以要先學會前面三種，才學得懂 Vue。第 8 章開始才會用到 Vue。

      重點

      一般的網頁，HTML 一定要有，CSS 和 JavaScript 可以沒有。只有 HTML 的網頁也能看，只是樣子很陽春、不會動。

      這本書的範例怎麼看

      書裡的 HTML 範例會像下面這樣：上半部是程式碼，下半部的「畫面」是瀏覽器照這段程式碼畫出來的結果。

      第一個範例
      <h1>你好</h1>
<p>這是我的第一個網頁。</p>
      畫面

      現在還不用看懂程式碼。先試一下右上角的「改改看」按鈕：

      1. 按「改改看」，程式碼的框會出現虛線，表示可以打字了。
      2. 把 你好 改成你的名字。
      3. 看下面的「畫面」，大約半秒後就會跟著變。
      4. 改壞了也沒關係，按「還原」就會回到原本的樣子。

      你在書裡改的東西不會被存起來，重新整理頁面就會回到原樣。要留下來的作品，要照 0.3 節的方法存成自己的檔案。

      0.2 安裝兩個軟體：瀏覽器和 VS Code

      寫網頁只需要兩個軟體：

      軟體做什麼比喻
      瀏覽器打開網頁檔，把畫面畫出來；也用來找錯電視機
      VS Code打程式碼、存檔的文字編輯器紙和筆

      瀏覽器

      本書用 Google Chrome 說明。Windows 內建的 Edge 和 Chrome 是同一個核心做的，畫面和按鍵幾乎一樣，用 Edge 也可以。Mac 內建的 Safari 也能看網頁，但 0.5 節的開發者工具要另外打開設定，所以建議另外裝 Chrome。

      1. 到 Chrome 下載頁，按「下載 Chrome」。
      2. Mac：打開下載的 googlechrome.dmg，把 Chrome 圖示拖到「應用程式」資料夾。
      3. Windows：雙擊下載的安裝檔，等它自己裝完。

      VS Code

      VS Code（Visual Studio Code）是微軟出的免費編輯器，現在寫網頁的人大多用它。它會幫程式碼上色、自動補字，比電腦內建的記事本好用很多。

      1. 到 VS Code 官網，按下載按鈕。網站會自動選你的作業系統。
      2. Mac：下載的是一個 .zip，雙擊解開後會出現 Visual Studio Code 圖示，把它拖到「應用程式」資料夾。
      3. Windows：雙擊下載的安裝檔，選「我同意」，其他一路按「下一步」到裝完。

      VS Code 一開始是英文介面。想換成中文：打開 VS Code，按左邊一排圖示裡的「方塊」圖示（Extensions，擴充功能），搜尋 Chinese (Traditional)，安裝第一個結果，再照右下角的提示重新啟動。不換也完全不影響學習，本書提到選單時會中英文都寫。

      陷阱

      不要用 Mac 的「文字編輯」（TextEdit）或 Word 寫網頁。它們存檔時會偷偷加上排版資料，瀏覽器讀到的就不是你打的那些字了。Windows 的「記事本」雖然可以用，但很容易存成 .txt（下一節會講），也沒有上色和自動補字。

      0.3 做出第一個網頁檔

      第一步：建一個資料夾

      先在電腦上建一個資料夾，之後的練習都放在這裡。例如在「文件」裡建一個叫 vue-book 的資料夾。

      資料夾和檔案名稱建議只用英文小寫、數字和 -，不要用中文和空白。現在用中文還不會出問題，但第 15 章開始用的工具，遇到中文或空白的路徑偶爾會出錯，從一開始就養成習慣比較省事。

      第二步：用 VS Code 打開這個資料夾

      1. 打開 VS Code，選上方選單 File → Open Folder…（檔案 → 開啟資料夾），選剛剛的 vue-book。
      2. 如果跳出「Do you trust the authors…」（是否信任這個資料夾的作者），按 Yes, I trust the authors。這是你自己建的資料夾，可以信任。
      3. 左邊會出現檔案總管，最上面寫著 VUE-BOOK。

      第三步：新增檔案 index.html

      1. 把滑鼠移到左邊的 VUE-BOOK 上，會出現幾個小圖示，按第一個「New File…」（新增檔案）。
      2. 輸入檔名 index.html，按 Enter。右邊會打開這個空白檔案。
      3. 在檔案裡打一個驚嘆號 !，等一下會跳出提示選單，按 Enter（或 Tab）。

      VS Code 會自動幫你填好一整份網頁的基本架構，叫做「樣板」：

      HTML
      <!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Document</title>
</head>
<body>

</body>
</html>

      每一行是什麼意思，第 1 章 1.2 節會一行一行講。現在只要知道：要顯示在網頁上的東西，寫在 <body> 和 </body> 中間。

      把游標移到 <body> 下面那個空行，打上：

      HTML
      <h1>我的第一個網頁</h1>
<p>今天開始學寫網頁。</p>

      然後存檔：Mac 按 Cmd＋S，Windows 按 Ctrl＋S。

      陷阱

      沒存檔的檔案，VS Code 上方的檔名標籤旁邊會有一個白色圓點，存好之後圓點會變回 ×。瀏覽器讀的是存在硬碟裡的檔案，沒存檔的話，你打的字瀏覽器根本看不到。初學者最常見的「我改了怎麼沒變」，九成是忘了存檔。

      第四步：用瀏覽器打開

      到資料夾裡找到 index.html，雙擊它，電腦會用預設的瀏覽器打開。也可以直接把檔案拖進瀏覽器視窗。

      打開後看瀏覽器上方的網址列，會看到類似這樣的網址，表示瀏覽器讀的是你電腦裡的檔案，不是網路上的：

      file:///Users/你的名字/Documents/vue-book/index.html          ← Mac
file:///C:/Users/你的名字/Documents/vue-book/index.html       ← Windows

      Windows 的副檔名陷阱

      檔名最後面的 .html 叫副檔名，電腦靠它判斷這是什麼檔。Windows 預設會把副檔名藏起來，所以你看到的檔名 index.html 可能其實是 index.html.txt，瀏覽器就會把它當成純文字，直接把你打的程式碼原封不動顯示出來。

      用 VS Code 建檔通常不會發生這種事，但用其他方式建檔就很常見。建議先讓 Windows 把副檔名顯示出來：

      • Windows 11：打開檔案總管，按上方的「檢視」→「顯示」→ 勾選「副檔名」。
      • Windows 10：打開檔案總管，按上方的「檢視」分頁，勾選「副檔名」。

      Mac 的 Finder 也可能隱藏副檔名。要顯示的話：Finder 上方選單「Finder → 設定 → 進階」，勾選顯示副檔名的那一項（英文介面寫 Show all filename extensions）。

      重點

      打開網頁卻看到一整片程式碼（連 <h1> 都顯示出來），先檢查副檔名是不是 .html。

      0.4 改程式的循環：改 → 存 → 重新整理

      寫網頁的日常，就是一直重複這三步：

      1. 改在 VS Code 改程式碼
      2. 存Mac 按 Cmd＋S，Windows 按 Ctrl＋S
      3. 重新整理回到瀏覽器，Mac 按 Cmd＋R，Windows 按 F5 或 Ctrl＋R

      瀏覽器只在「打開」或「重新整理」的那一刻讀檔案。之後你再怎麼改檔案、存檔，瀏覽器畫面都不會自己變，要按重新整理它才會重讀一次。

      動手試一次：把 index.html 裡的「我的第一個網頁」改成「我的網頁」→ 存檔 → 回瀏覽器重新整理，確認標題變了。

      你做了什麼瀏覽器畫面會變嗎為什麼
      改了，沒存檔，按重新整理不會硬碟裡的檔案還是舊的
      改了，存檔，沒按重新整理不會瀏覽器還沒重新讀檔
      改了，存檔，按重新整理會三步都做了

      覺得每次都要按存檔很麻煩，可以打開 VS Code 的自動存檔：選單 File → Auto Save（檔案 → 自動儲存），前面出現勾勾就表示開了。開了以後只剩「改」和「重新整理」兩步。

      重點

      第 15 章會用到一套工具，存檔後瀏覽器會自己更新，連重新整理都不用按。在那之前，記住「改 → 存 → 重新整理」。

      試試 Elements

      打開你的 index.html，再打開開發者工具，點 Elements。你會看到剛才打的 <h1> 和 <p>。把滑鼠移到 <h1> 那一行，網頁上的標題會被藍色框起來，告訴你這一行對應畫面上的哪一塊。

      你也可以在 Elements 裡雙擊文字直接改，畫面會馬上變。但這只是暫時改了瀏覽器裡的那一份，不會改到你的檔案，重新整理就沒了。它適合用來「先試試看」，確定要改了，還是要回 VS Code 改檔案。

      試試 Console

      點 Console，在最下面有 > 符號的那一行打：

      1 + 1

      按 Enter，下一行會出現 2。你剛剛執行了第一行 JavaScript。Console 會把你打的東西當成 JavaScript 執行，再把結果顯示出來。第 3 章會常常在這裡做實驗。

      陷阱

      如果你是貼上程式碼，而不是自己打字，Chrome 可能會跳出警告，要你先打 allow pasting 才能貼。這是 Chrome 的防詐騙設計：壞人常叫別人把一段程式碼貼進 Console 來偷資料。來源不明的程式碼，不要貼進 Console。

      重點

      程式跑不出預期的結果時，第一件事就是打開開發者工具看 Console 有沒有紅字。紅字就是錯誤訊息，會告訴你錯在哪一行。

      • 網頁由三種文字組成：HTML 管有什麼、CSS 管長什麼樣、JavaScript 管會做什麼。Vue 是用 JavaScript 寫成的工具，第 8 章才用到。
      • 寫網頁要兩個軟體：瀏覽器（Chrome 或 Edge）和 VS Code。不要用文字編輯（TextEdit）或 Word。
      • 網頁檔的副檔名是 .html。Windows 預設會藏副檔名，小心存成 .html.txt。
      • 在 VS Code 的 .html 檔裡打 ! 再按 Enter，會自動產生網頁樣板。要顯示的內容寫在 <body> 裡。

      這一章學 HTML，也就是網頁的骨架。念完你會：看懂一個標籤由哪幾個部分組成、知道一份網頁檔的基本架構每一行在做什麼、會放標題、段落、連結、圖片、清單、表格和輸入框，最後學會用 div、class、id 把網頁分區。這些都是之後寫 Vue 畫面的基本材料。

      1.1 標籤：HTML 的基本單位

      HTML 用標籤（tag）告訴瀏覽器「這段文字是什麼東西」。例如這是一個大標題、那是一段文字。看一個最簡單的例子：

      HTML
      <h1>今天的記帳</h1>
<p>早餐花了 60 元。</p>
      畫面

      拆開第一行看，它由三個部分組成：

      部分寫法意思
      開始標籤<h1>告訴瀏覽器：「大標題從這裡開始」
      內容今天的記帳要顯示的文字
      結束標籤</h1>告訴瀏覽器：「大標題到這裡結束」。和開始標籤一樣，只是多了一條斜線 /

      開始標籤、內容、結束標籤合起來，叫做一個元素（element）。所以上面的例子有兩個元素：一個 h1 元素、一個 p 元素。

      重點

      標籤是用尖括號 < > 包起來的名稱。結束標籤在名稱前面多一條斜線 /。標籤本身不會顯示在畫面上，顯示的只有內容。

      標題與段落

      h 是 heading（標題）的縮寫。HTML 有 h1 到 h6 六級標題，h1 最大、最重要，h6 最小。p 是 paragraph（段落）的縮寫，用來放一般的文字。

      六級標題和段落
      <h1>h1 大標題</h1>
<h2>h2 第二級</h2>
<h3>h3 第三級</h3>
<h6>h6 最小的標題</h6>
<p>這是一個段落。</p>
<p>這是另一個段落，兩個段落之間會自動空一點距離。</p>
      畫面

      標題要照順序用：大標題用 h1，底下的小節用 h2，再下一層用 h3。不要因為「想要字小一點」就跳去用 h4。字的大小是外觀，第 2 章會用 CSS 調整。HTML 只負責說「這是第幾級標題」。

      陷阱

      結束標籤的斜線很容易漏打。寫成 <h1>標題<h1> 的話，瀏覽器會以為第二個 <h1> 是另一個標題的開始，後面的文字全部被當成大標題。畫面突然出現一大片粗大的字，先檢查結束標籤有沒有斜線。

      1.2 一份網頁檔的基本架構

      第 0 章在 VS Code 打 ! 產生的樣板，每一行都有作用。現在一行一行看：

      HTML
      <!DOCTYPE html>
<html lang="zh-Hant">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>我的記帳本</title>
</head>
<body>
    <h1>今天的記帳</h1>
</body>
</html>
      這一行做什麼
      <!DOCTYPE html>告訴瀏覽器：「這是一份用現代 HTML 寫的網頁」。永遠放在第一行，照抄就好
      <html lang="zh-Hant">整份網頁的最外層。lang 說明網頁用什麼語言，zh-Hant 是繁體中文。樣板預設的 en 是英文，改成中文比較正確
      <head> … </head>網頁的「頭」：放給瀏覽器看的設定，不會顯示在頁面內容裡
      <meta charset="UTF-8">告訴瀏覽器這份檔案用 UTF-8 編碼。少了它，中文可能變成亂碼
      <meta name="viewport" …>讓網頁在手機上用正確的寬度顯示。少了它，手機會把網頁縮得很小
      <title> … </title>網頁的名稱，顯示在瀏覽器分頁標籤上，不是顯示在頁面裡
      <body> … </body>網頁的「身體」：所有要顯示給人看的內容都寫在這裡

      <!DOCTYPE html> 和 <meta charset>、<meta name="viewport"> 這種寫一次就不用管的設定，每份網頁都長得一樣，用 VS Code 的 ! 產生就好，不用背。真正要每天寫的只有 <body> 裡面。

      陷阱

      <title> 不是頁面上的大標題。它只出現在瀏覽器分頁標籤上，還有加入書籤時的名稱。頁面上的大標題要用 <h1>。

      為什麼要 meta charset

      電腦存文字時，要把每個字轉成數字存起來，轉換的規則叫編碼。VS Code 預設用 UTF-8 這套規則存檔。瀏覽器讀檔時，如果沒有人告訴它檔案是用哪套規則存的，它只能用猜的，猜錯就會把中文顯示成「ä»Šå¤©」這種亂碼。<meta charset="UTF-8"> 就是直接告訴瀏覽器答案，不讓它猜。

      重點

      書裡的 HTML 範例為了簡短，只寫 <body> 裡面的內容。你自己存成檔案時，一定要放進完整的樣板裡。

      1.3 元素裡面放元素，以及空白和換行

      巢狀

      元素裡面可以再放元素，叫做巢狀（nesting）。例如在段落裡，想把某幾個字變粗體強調，可以用 <strong>：

      HTML
      <p>早餐花了 <strong>60 元</strong>，有點貴。</p>
      畫面

      strong 元素整個被包在 p 元素裡面。這時我們說 p 是 strong 的父元素（parent），strong 是 p 的子元素（child）。前面的 <html> 包著 <head> 和 <body>，也是同樣的關係。

      巢狀有一個規則：先開的後關。像收納盒一樣，小盒子要整個放進大盒子裡，不能一半在裡面一半在外面。

      寫法對不對原因
      <p>花了 <strong>60 元</strong></p>對strong 先關，p 後關，strong 整個在 p 裡面
      <p>花了 <strong>60 元</p></strong>錯p 先關了，strong 卻還沒關，兩個盒子交叉了

      寫錯的話，瀏覽器不會跳出錯誤訊息，而是自己猜你想怎樣、自動修正，畫出來的結果常常跟你想的不一樣。HTML 寫錯不會報錯，所以畫面怪怪的時候，要打開開發者工具的 Elements，看瀏覽器實際修成什麼樣子。

      縮排

      裡層的元素通常會往右縮排，讓人一眼看出誰包著誰。縮排只是給人看的，瀏覽器不在乎。下面兩種寫法，畫出來完全一樣：

      HTML
      <body><h1>記帳</h1><p>早餐 60 元</p></body>

<body>
    <h1>記帳</h1>
    <p>早餐 60 元</p>
</body>

      第二種好讀很多，所以大家都這樣寫。VS Code 裡選取幾行後按 Tab 會往右縮，按 Shift＋Tab 往左縮。

      空白和換行會被合併

      這是初學者最常嚇一跳的地方：你在程式碼裡按的 Enter 和連續空白，瀏覽器都不會照樣顯示。連續的空白、換行，全部被當成一個空白。

      在程式碼裡換行和空很多格
      <p>早餐 60 元
午餐 120 元
晚餐     200 元</p>
      畫面

      三行字被接成一行，「晚餐」後面的五個空白也只剩一個。想要換行有兩種做法：

      • 分成不同段落：每一筆寫成一個 <p>。這是比較好的做法，因為它們本來就是不同的東西。
      • 用 <br> 強制換行：br 是 break（斷開）的縮寫。它只是在原地換行，適合地址、詩句這種「同一段文字但要分行」的情況。
      用 br 換行
      <p>早餐 60 元<br>午餐 120 元<br>晚餐 200 元</p>
      畫面

      注意 <br> 沒有結束標籤，因為它裡面不會放任何內容。這種元素叫空元素（void element），下一節的 <img> 也是。

      重點

      程式碼裡的換行和連續空白，在畫面上只算一個空白。要分段用 <p>，要在同一段裡換行用 <br>。

      1.4 屬性：連結和圖片

      HTML

      畫面

      清單

      第 12 章 Vue 的 v-model，就是把這些輸入框和資料綁在一起：使用者一打字，資料就跟著變。

      前面的元素都有特定意思：h1 是標題、p 是段落、li 是清單項目。但有時候你只是想把幾個東西「包成一組」，好讓 CSS 一起調整樣式，或讓 JavaScript 一起處理。這時用兩個本身沒有意思的元素：

      spanspan（一小段）包住一行文字裡的一小段，例如金額數字。不會換行

    <p>金額：<span>120</span> 元</p>
</div>

      網頁上有很多 div，CSS 和 JavaScript 要怎麼指定「是哪一個」？方法是替元素加上 class 或 id 屬性：

      HTML

      1.8 註解，以及用開發者工具看 HTML

      註解

      寫在 <!-- 和 --> 中間的文字叫註解（comment）。瀏覽器會完全忽略它，畫面上不會顯示。用來替自己或同事寫說明，或者暫時把一段程式碼「關掉」又不想刪掉：

      HTML

<p>晚餐 200 元</p>

      畫面上只有早餐和晚餐，午餐那一行被註解包住，瀏覽器就不畫了。在 VS Code 裡選取幾行，按 Cmd＋/（Windows 是 Ctrl＋/）可以一次加上或拿掉註解。

      陷阱

      註解不會顯示在畫面上，但任何人都看得到。在網頁上按右鍵選「檢視網頁原始碼」，註解就在裡面。密碼、內部資訊絕對不要寫在 HTML 註解裡。

      用 Elements 看結構

      第 0 章打開過開發者工具的 Elements 分頁。現在你看得懂裡面的東西了：它顯示的就是網頁的元素，用縮排和三角形箭頭表示誰包著誰。點三角形可以展開或收起子元素。

      重點

      畫面不如預期時，用 Elements 的箭頭工具點那個地方，看瀏覽器實際看到的結構。

      1.9 本章整理

      • 元素 ＝ 開始標籤 ＋ 內容 ＋ 結束標籤。結束標籤多一條斜線，例如 <p>…</p>。
      • 網頁樣板：<head> 放設定（meta charset 防亂碼、title 是分頁標籤上的名稱），<body> 放要顯示的內容。
      • 標題 h1～h6 照層級用，段落用 p，強調用 strong。
      • 巢狀要「先開的後關」，不能交叉。HTML 寫錯不會報錯，瀏覽器會自己猜，要用 Elements 檢查。
      • 程式碼裡的換行和連續空白只算一個空白。分段用 p，同一段換行用 br。
      • 屬性寫在開始標籤裡：名稱="值"，多個屬性用空白隔開。連結 <a href>、圖片 <img src alt>。
      • 相對網址從目前 HTML 檔所在的資料夾開始找，檔名用小寫最保險。
      • 沒有內容的空元素沒有結束標籤：br、img、input。
      • 清單：ul（圓點）、ol（編號），每項都是 li。表格：table 裡一列一個 tr，格子用 th（標題）或 td（資料）。
      • 表單元素：input 換 type 就變不同的框（text、number、checkbox），下拉選單 select＋option，按鈕 button。label 的 for 對上輸入框的 id。
      • 布林屬性（如 checked）只看有沒有寫，不看值。
      • div 包一大塊、span 包一小段，本身沒有樣式。id 全頁唯一，class 可以重複、一個元素可以有好幾個。
      • 註解 <!-- --> 不會顯示，但任何人都看得到原始碼。

      這一章學 CSS，負責網頁的外觀。念完你會：知道 CSS 寫在哪裡、看懂一條規則的每個部分、用選擇器指定要改哪些元素、知道兩條規則打架時誰會贏、會調顏色和文字，最後學會「盒子模型」和用 Flexbox 把東西排成一排。這些就足夠把第 18 章的記帳網頁排得整整齊齊。

      2.1 CSS 寫在哪裡

      CSS 是 Cascading Style Sheets（層疊樣式表）的縮寫。它是另一種語言，專門描述「HTML 元素長什麼樣子」。CSS 有三種寫法：

      寫法一：寫在 style 元素裡（本書範例最常用）

      HTML
      <style>
    h1 {
        color: green;
    }
</style>
<h1>今天的記帳</h1>
<p>早餐 60 元</p>
      畫面

      <style> 和 </style> 中間寫的就是 CSS，不是 HTML。上面那條的意思是：「所有 h1 的文字顏色都改成綠色」。p 沒有被指定，所以還是黑色。

      在完整的網頁檔裡，<style> 要放在 <head> 裡面，因為它是「設定」，不是要顯示的內容。書裡的範例為了簡短，直接放在最前面，畫出來的效果一樣。

      寫法二：寫在另一個 .css 檔，用 link 引進來

      網站有很多頁時，把 CSS 統一寫在一個 .css 檔，每一頁用 <link> 引進來，改一個檔就能改全部頁面：

      HTML
      <!-- index.html 的 head 裡 -->
<link rel="stylesheet" href="style.css">
      CSS
      /* style.css：這個檔裡只寫 CSS，不用寫 <style> */
h1 {
    color: green;
}

      rel="stylesheet" 說明「這是樣式表」，href 是 .css 檔的位置，用的是第 1 章學過的相對網址。

      寫法三：寫在元素的 style 屬性裡

      HTML
      <h1 style="color: green;">今天的記帳</h1>

      這樣只會影響這一個元素。寫起來快，但東西一多就很難管理，因為樣式散落在各個元素上，要改得一個一個找。只在臨時測試，或第 10 章 Vue 用資料動態改樣式時才會用到。

      重點

      初學時把 CSS 寫在 <style> 裡最方便。網站變大以後改成獨立的 .css 檔。style 屬性盡量少用。

      2.2 一條 CSS 規則的寫法

      CSS 是由一條一條規則（rule）組成的。拆開下面這條看：

      CSS
      p {
    color: red;
    font-size: 20px;
}
      部分寫法意思
      選擇器（selector）p要改哪些元素。這裡是所有的 p
      大括號{ … }包住這條規則的所有設定
      屬性（property）color、font-size要改什麼：文字顏色、文字大小
      冒號:分隔屬性和值
      值（value）red、20px要改成什麼
      分號;一個設定結束。每個設定後面都要加

      屬性: 值; 這一組叫一個宣告（declaration）。一條規則裡可以有很多個宣告，習慣上一行寫一個。

      注意 CSS 的「屬性」和 HTML 的「屬性」雖然中文一樣，是兩回事：HTML 的屬性寫在標籤裡（href="…"），CSS 的屬性寫在大括號裡（color: red）。

      寫錯時會怎樣

      CSS 跟 HTML 一樣，寫錯不會出現錯誤訊息。瀏覽器會跳過看不懂的那個宣告，其他的照常套用。最常見的錯有兩種：

      漏了分號
      <style>
    p {
        color: red
        font-size: 30px;
    }
</style>
<p>早餐 60 元</p>
      畫面

      color: red 後面少了分號，瀏覽器就讀成一個很長的值「red font-size: 30px」。這不是合法的顏色，於是整個宣告被丟掉，連下一行的 font-size 也一起失效。所以字還是黑色、大小也沒變。按「改改看」把分號補上，兩個設定都會生效。

      打成全形冒號
      <style>
    p {
        color：red;
        font-size: 30px;
    }
</style>
<p>早餐 60 元</p>
      畫面

      color：red 用的是中文輸入法打出來的全形冒號 ：，瀏覽器不認得，這個宣告被跳過。但它後面有分號，所以下一行的 font-size 不受影響，字還是變大了。

      陷阱

      寫程式時要切換成英文輸入法。中文輸入法打出的全形 ：；｛｝＂，看起來和半形的 :;{}" 很像，但電腦完全當成不同的字。在 VS Code 裡，看不懂的 CSS 底下通常會出現波浪線，可以幫你找到這種錯。

      2.3 選擇器：指定要改哪些元素

      選擇器決定「這條規則套用到誰身上」。最常用的有下面幾種：

      種類寫法選到誰
      標籤選擇器p所有 p 元素
      class 選擇器.money所有 class 裡有 money 的元素。前面加一個點
      id 選擇器#totalid 是 total 的那一個元素。前面加一個井字號
      後代選擇器.card span在 .card 裡面的所有 span。兩個選擇器中間用空白隔開
      群組h1, h2h1 和 h2 都套用。用逗號隔開
      各種選擇器
      <style>
    .money {
        color: red;
    }
    #total {
        font-weight: bold;
    }
    .card span {
        background-color: yellow;
    }
</style>
<div class="card">
    <p>早餐 <span class="money">60</span> 元</p>
    <p>午餐 <span>120</span> 元</p>
</div>
<p>外面的 <span>span</span> 不受 .card span 影響</p>
<p id="total">合計 <span class="money">180</span> 元</p>
      畫面

      對照畫面一條一條看：

      • .money：「60」和「180」都是紅字，因為它們都有 class="money"。一條規則同時套到兩個元素上，這就是 class 好用的地方。
      • #total：只有「合計」那一行變粗。
      • .card span：「60」和「120」有黃底，因為它們在 class="card" 的 div 裡面。第三行的 span 在 .card 外面，所以沒有黃底。「180」也在外面，所以只有紅字、沒有黃底。
      陷阱

      選擇器裡的點和井字號只在 CSS 裡寫，HTML 裡不寫。HTML 寫 class="money"，CSS 寫 .money。寫成 class=".money" 的話，CSS 的 .money 就選不到它。

      陷阱

      後代選擇器中間的空白很重要。.card span 是「.card 裡面的 span」；.card, span 多了一個逗號，意思就變成「.card 和所有 span」，差很多。

      2.4 兩條規則打架時，誰會贏

      同一個元素常常同時被好幾條規則選到。如果它們設定了同一個屬性，例如都設了 color，只會有一個生效。瀏覽器照下面的順序決定誰贏：

      規則一：選擇器越「具體」越強

      選擇器指得越精準，分量越重：

      1. 標籤p：所有段落，最籠統
      2. class.money：某一類元素
      3. id#total：唯一的那一個，最具體
      HTML
      <style>
    #total {
        color: green;
    }
    .money {
        color: red;
    }
    p {
        color: blue;
    }
</style>
<p>一般段落</p>
<p class="money">有 class 的段落</p>
<p id="total" class="money">有 id 也有 class 的段落</p>
      畫面
      段落被哪些規則選到誰贏結果
      第一段p只有一條藍
      第二段p、.moneyclass 比標籤具體紅
      第三段p、.money、#totalid 最具體綠

      注意 #total 明明寫在最前面，還是贏了。具體程度比寫的順序重要。

      規則二：一樣具體時，後寫的贏

      HTML
      <style>
    .money {
        color: red;
    }
    .highlight {
        color: orange;
    }
</style>
<p class="money highlight">60 元</p>
      畫面

      兩條都是 class 選擇器，一樣具體，所以看誰寫在後面：.highlight 在後，字是橘色。注意，這裡看的是 CSS 裡規則的順序，跟 HTML 裡 class="money highlight" 兩個名字的順序無關。按「改改看」把 HTML 改成 class="highlight money"，顏色不會變；把 CSS 兩條規則上下對調，才會變成紅色。

      規則三：style 屬性比所有選擇器都強

      直接寫在元素上的 style="…"，會贏過 <style> 裡的任何選擇器，連 id 也贏不了它。這也是 2.1 節說盡量少用的原因之一：它太強了，之後想用 CSS 蓋過去很麻煩。

      繼承：沒設定的，有些會跟爸爸一樣

      有些屬性，父元素設了，子元素沒設的話，會自動跟著父元素，叫做繼承。文字相關的屬性大多會繼承，盒子相關的大多不會：

      HTML
      <style>
    .card {
        color: purple;
        border: 2px solid gray;
    }
</style>
<div class="card">
    <p>早餐 <strong>60</strong> 元</p>
</div>
      畫面

      div 設了紫色字，裡面的 p 和 strong 都沒設顏色，所以都繼承成紫色。但 border（邊框，2.6 節會講）不會繼承，所以只有外面的 div 有框，p 自己沒有框。如果邊框會繼承，每一層都會多一個框，那就太亂了。

      會繼承（文字類）不會繼承（盒子類）
      color、font-size、font-weight、text-alignborder、padding、margin、width、background-color

      background-color 不會繼承，但子元素的背景預設是透明的，所以看起來會「透出」父元素的底色。這不是繼承，是透明。

      重點

      誰贏的判斷順序：style 屬性 ＞ id ＞ class ＞ 標籤；一樣具體時後寫的贏。自己完全沒被任何規則設定到的屬性，才會去看繼承。

      2.5 顏色和文字

      顏色的寫法

      寫法例子說明
      英文名稱red、green、gray最好懂，但只有固定的一百多種
      十六進位#e53935# 後面六個字，每兩個一組，依序是紅、綠、藍的量（00 最少、ff 最多）。設計稿上的顏色大多用這種
      rgbrgb(229, 57, 53)紅、綠、藍各是 0～255。和上面的 #e53935 是同一個顏色

      顏色不用自己算。VS Code 在 CSS 的顏色值旁邊會顯示一個小色塊，點它就會跳出調色盤。

      常用的文字和顏色屬性

      HTML
      <style>
    .title {
        color: white;
        background-color: #2e7d32;
        font-size: 24px;
        text-align: center;
    }
    .money {
        font-weight: bold;
        font-size: 150%;
    }
</style>
<p class="title">本月支出</p>
<p>合計 <span class="money">3,280</span> 元</p>
      畫面
      屬性管什麼常用的值
      color文字顏色任何顏色
      background-color背景顏色任何顏色
      font-size文字大小16px、150%
      font-weight文字粗細normal（一般）、bold（粗）
      text-align文字在這一塊裡怎麼對齊left、center、right

      單位：px 和 %

      px 是 pixel（像素），螢幕上的一個小點，是最直接的單位。瀏覽器預設的文字大小是 16px。

      % 是「相對於某個東西的百分之幾」。在 font-size 裡，是相對於父元素的文字大小。上面的「3,280」在 p 裡面，p 是預設的 16px，所以 150% 就是 16 × 1.5 ＝ 24px。同樣是 150%，放在 20px 的父元素裡就會變成 30px。

      陷阱

      數字和單位之間不能有空白：16px 正確，16 px 會被當成看不懂的值而跳過。另外除了 0 以外，數字一定要帶單位：font-size: 16 沒有單位，也會被跳過。

      2.6 盒子模型：每個元素都是一個盒子

      在瀏覽器眼中，每個元素都是一個長方形的盒子。這個盒子由內到外有四層：

      層屬性比喻（裱框的畫）
      內容（content）width、height畫本身
      內距（padding）padding畫和框之間的白邊
      邊框（border）border畫框
      外距（margin）margin這幅畫和隔壁那幅畫之間的牆面空隙
      一張記帳卡片
      <style>
    .card {
        width: 200px;
        padding: 16px;
        border: 2px solid #2e7d32;
        margin: 12px;
        background-color: #e8f5e9;
    }
</style>
<div class="card">早餐 60 元</div>
<div class="card">午餐 120 元</div>
      畫面

      看畫面：淺綠色的背景會塗滿內容＋內距，然後是綠色的框，框外面的空隙是外距，所以兩張卡片之間隔開了。

      border 的寫法

      border: 2px solid #2e7d32; 一次寫了三件事，用空白隔開：

      部分意思其他常用的值
      2px框的粗細1px
      solid框的樣式：實線dashed（虛線）、dotted（點線）
      #2e7d32框的顏色任何顏色

      solid 這一項不能省略。只寫 border: 2px #2e7d32; 的話樣式預設是「沒有框」，什麼都看不到。

      padding 和 margin 的寫法

      padding: 16px; 是上下左右四邊都 16px。也可以分開設：

      寫法意思
      padding: 16px;四邊都是 16px
      padding: 8px 16px;上下 8px，左右 16px
      padding-top: 8px;只設上面。另外還有 -right、-bottom、-left

      margin 的寫法完全一樣。另外，margin: 0 auto; 是一個常見的技巧：上下 0、左右「自動平分剩下的空間」，可以讓一個有設寬度的盒子在畫面上水平置中。

      盒子到底多寬：box-sizing

      上面的卡片設了 width: 200px，但它在畫面上其實是 236px 寬。因為預設情況下，width 只管內容那一層，內距和邊框要另外加上去：

      左邊框 2 ＋ 左內距 16 ＋ 內容 200 ＋ 右內距 16 ＋ 右邊框 2 ＝ 236px

      （外距不算在盒子的寬度裡，它是盒子外面的空隙。）

      這很不直覺：想要一張 200px 的卡片，還得自己扣掉內距和邊框。所以現在幾乎所有網站都會在 CSS 最前面加上這一條，讓 width 改成包含內距和邊框：

      加上 box-sizing: border-box
      <style>
    * {
        box-sizing: border-box;
    }
    .card {
        width: 200px;
        padding: 16px;
        border: 2px solid #2e7d32;
        background-color: #e8f5e9;
    }
</style>
<div class="card">早餐 60 元</div>
      畫面

      * 是「所有元素」的選擇器。加了這條以後，卡片就是剛好 200px，內容區自動縮成 200 − 32 − 4 ＝ 164px。本書之後的範例，只要用到寬度，都會加上這條。

      重點

      盒子由內到外：內容 → 內距 padding → 邊框 border → 外距 margin。預設的 width 只算內容；加上 box-sizing: border-box 後，width 會包含內距和邊框。

      用 CSS 畫表格格線

      第 1 章用 border="1" 畫表格線。用 CSS 的正式做法是替每一格加邊框，再把相鄰的框合併成一條線：

      HTML
      <style>
    table {
        border-collapse: collapse;
    }
    th, td {
        border: 1px solid #999;
        padding: 4px 12px;
    }
</style>
<table>
    <tr><th>項目</th><th>金額</th></tr>
    <tr><td>早餐</td><td>60</td></tr>
    <tr><td>午餐</td><td>120</td></tr>
</table>
      畫面

      border-collapse: collapse 的意思是「相鄰格子的框合併」。按「改改看」把這一行刪掉，就會看到每一格各自有框、中間變成雙線。

      2.7 區塊元素和行內元素

      第 1 章說 div 會獨佔一行、span 不會。原因是每個元素都有一個預設的顯示方式（display）：

      區塊元素（block）行內元素（inline）
      例子div、p、h1～h6、ul、li、tablespan、a、strong、img
      排列方式獨佔一整行，下一個元素一定從下一行開始像文字一樣排在同一行，排滿了才換行
      寬度沒設的話，自動撐滿父元素的寬度跟著內容一樣寬
      能不能設 width、height可以不行，設了也沒用（img 例外）
      HTML
      <style>
    div, span {
        border: 1px solid #e53935;
        width: 120px;
    }
</style>
<div>div 一</div>
<div>div 二</div>
<span>span 一</span>
<span>span 二</span>
      畫面

      兩個 div 上下排，各佔一行，寬度照設定的 120px（加上框）。兩個 span 排在同一行，寬度只跟著文字，width: 120px 對它們完全沒有作用。

      用 display 改變顯示方式

      元素預設是哪一種，可以用 display 屬性改掉：

      寫法效果
      display: block;變成區塊元素。例如讓 a 連結獨佔一行、可以設寬高，做成大按鈕
      display: inline;變成行內元素。例如讓 li 排成一排
      display: inline-block;排在同一行，但可以設寬高，兩者的優點都有
      display: none;整個不顯示，也不佔空間，就像不存在一樣

      display: none 很重要，第 11 章 Vue 的 v-show 就是用它把東西藏起來的。下一節的 display: flex 則是現在排版的主力。

      2.8 Flexbox：把東西排成一排

      做網頁時最常遇到的排版需求：把幾個東西排成橫的一排，例如「項目在左邊、金額在右邊」。區塊元素會一個疊一個往下排，做不到這件事。這時用 Flexbox：在父元素加上 display: flex，它的子元素就會改成橫向排列。

      HTML
      <style>
    .row {
        display: flex;
        border: 1px solid #999;
    }
</style>
<div class="row">
    <div>早餐</div>
    <div>60 元</div>
</div>
      畫面

      兩個 div 本來會上下排，現在變成左右排了。注意 display: flex 是加在外面那一層（.row）身上，被影響的是它的子元素。

      接下來用幾個屬性調整子元素怎麼排。這些屬性也都寫在父元素上：

      記帳列表的一行
      <style>
    * {
        box-sizing: border-box;
    }
    .row {
        display: flex;
        justify-content: space-between;
        align-items: center;
        gap: 8px;
        padding: 8px 12px;
        border-bottom: 1px solid #ddd;
    }
    .money {
        font-size: 20px;
        font-weight: bold;
    }
</style>
<div class="row">
    <span>早餐</span>
    <span class="money">60</span>
</div>
<div class="row">
    <span>午餐</span>
    <span class="money">120</span>
</div>
      畫面
      屬性管什麼常用的值
      justify-content子元素在橫向怎麼分配flex-start（靠左，預設）、center（置中）、flex-end（靠右）、space-between（第一個靠最左、最後一個靠最右，剩下的空間平分在中間）
      align-items子元素在直向怎麼對齊stretch（拉成一樣高，預設）、center（垂直置中）
      gap子元素之間的間距8px
      flex-direction排列方向row（橫排，預設）、column（直排）

      上面的例子：space-between 讓項目靠左、金額靠右；align-items: center 讓字比較大的金額和項目垂直對齊在中間。按「改改看」，把 space-between 換成 center 或 flex-end，看看差別。

      讓某一個子元素佔滿剩下的空間

      在子元素上加 flex: 1，它就會撐開、吃掉剩下的所有空間。常用在「輸入框佔滿、按鈕在右邊」這種版面：

      HTML
      <style>
    .add {
        display: flex;
        gap: 8px;
    }
    .add input {
        flex: 1;
    }
</style>
<div class="add">
    <input placeholder="項目">
    <button>新增</button>
</div>
      畫面
      陷阱

      初學者最常見的錯：把 display: flex 加在想要排成一排的那幾個元素自己身上。它要加在包住它們的父元素上。同樣地，justify-content、align-items、gap 也都寫在父元素上；只有 flex: 1 寫在子元素上。

      重點

      Flexbox 三步驟：①在父元素加 display: flex ②用 justify-content 調橫向、align-items 調直向 ③用 gap 調間距。

      CSS 沒生效，照順序查：①Styles 裡有沒有出現這條規則（沒有＝選擇器沒選到）②有沒有黃色警告圖示（有＝宣告寫錯了）③有沒有被劃掉（只劃掉沒警告＝打輸了）。

      2.10 本章整理

      • CSS 三種寫法：<style> 元素（放在 head）、外部 .css 檔用 <link rel="stylesheet"> 引入、元素的 style 屬性（盡量少用）。
      • 規則 ＝ 選擇器 ＋ { 屬性: 值; }。寫錯不會報錯，看不懂的宣告會被跳過；漏了分號會連下一個宣告一起失效。不要用全形符號。
      • 選擇器：p（標籤）、.money（class）、#total（id）、.card span（.card 裡的 span）、h1, h2（群組）。點和井字號只寫在 CSS 裡。
      • 打架時：style 屬性 ＞ id ＞ class ＞ 標籤；一樣具體時，CSS 裡後寫的贏。文字類屬性會繼承，盒子類不會。
      • 顏色可以用英文名稱、#rrggbb、rgb()。font-size 的 % 相對於父元素的文字大小。數字和單位之間不能有空白。
      • 盒子模型由內到外：內容 → padding → border → margin。border 要寫樣式（如 solid）才看得到。加上 * { box-sizing: border-box; }，width 就包含內距和邊框。
      • 區塊元素獨佔一行、可設寬高；行內元素排在同一行、設寬高沒用。display 可以改，display: none 會整個不顯示。
      • Flexbox：父元素加 display: flex，子元素橫排。justify-content 調橫向、align-items 調直向、gap 調間距；子元素加 flex: 1 撐滿剩下的空間。
      • CSS 沒生效，用開發者工具的 Styles 面板查：沒出現、有黃色警告圖示、被劃掉。

      從這一章開始寫真正的程式。念完你會：知道 JavaScript 寫在哪裡、怎麼看到結果，會用變數存資料，會做數字計算和文字組合，知道資料有哪幾種「型別」，還看得懂最常見的三種錯誤訊息。這一章的東西很基本，但後面每一章都會用到，一定要動手跑過。

      3.2 變數：替資料取名字

      寫程式時常常需要把資料「先記下來，等一下再用」。變數就是一個有名字的盒子，可以把資料放進去，之後用名字拿出來。

      JavaScript

      拆開 let breakfast = 60;：

      部分意思
      let宣告：「我要建立一個新變數」
      breakfast變數的名字，自己取
      =放進去（指定）。注意：這不是數學的「等於」

      之後寫 breakfast，就等於寫 60。第三行印出 60，第四行算出 60 ＋ 120 ＝ 180。

      陷阱

      = 在程式裡是「把右邊的值放進左邊的變數」，不是「左右相等」。所以 60 = breakfast 是錯的，因為 60 不是盒子，放不進東西。要比較兩個值是否相等，是另一個符號 ===，第 4 章會教。

      改變變數的值

      用 let 建立的變數，之後可以放新的值進去，舊的值就被換掉了。改的時候不要再寫 let：

      JavaScript

      3放進 60（0 被換掉）60
      5先算 60 ＋ 120 ＝ 180，再放回去180

      const：不能換的變數

      宣告變數還有另一個字 const（constant，常數）。用 const 建立的變數，之後不能再放別的值進去：

      JavaScript
      const price = 60;

console.log("這一行不會執行");
      輸出
      60

      第三行想放新的值進 price，程式就出錯停下來了，第四行沒有機會執行。錯誤訊息的意思是「對常數變數做了指定」。

      那為什麼要用一個「比較不能做事」的 const？因為大部分的變數建立之後就不需要再換。用 const，萬一你不小心改到它，程式會馬上報錯提醒你，而不是默默算錯。

      重點

      預設用 const；確定之後要換值的（像累加的 total），才用 let。Vue 的程式碼裡，你會看到絕大多數的變數都是 const。

      你可能會在網路上的舊程式碼看到 var，它是 let 的舊版，有一些奇怪的行為。現在都不用了，本書也不用。

      變數的命名規則

      3.4 文字（字串）

      程式裡的一段文字叫字串（string），要用引號包起來。單引號、雙引號、反引號三種都可以：

      JavaScript
      const a = "早餐";
const b = '午餐';
const c = `晚餐`;
console.log(a);
console.log(b);
console.log(c);
      輸出
      早餐
午餐
晚餐

      引號只是告訴程式「字串從這裡開始、到這裡結束」，本身不是字串的內容，所以印出來不會有引號。頭尾要用同一種引號。

      陷阱

      沒有引號的話，程式會把它當成變數名稱。console.log(breakfast) 是「印出叫 breakfast 的變數」，console.log("breakfast") 才是印出 breakfast 這幾個字。

      用 + 把字串接起來

      JavaScript
      const item = "早餐";
const price = 60;
console.log(item + "花了" + price + "元");
console.log(item + " " + price);
      輸出
      早餐花了60元
早餐 60

      + 遇到字串，意思就變成「接起來」。注意接起來時不會自動加空白，要空白得自己加一個 " "。

      樣板字串：用反引號更方便

      用 + 接很多段很容易漏掉空白或引號。用反引號（`）包起來的字串可以直接在裡面放變數，寫法是 ${變數}：

      JavaScript
      const item = "早餐";
const price = 60;
console.log(`${item}花了 ${price} 元`);
console.log(`兩份是 ${price * 2} 元`);
      輸出
      早餐花了 60 元
兩份是 120 元

      ${ } 裡面不只能放變數，也能放計算，例如 ${price * 2}。這種字串叫樣板字串（template literal）。反引號在鍵盤左上角，數字 1 的左邊（要切到英文輸入法）。

      陷阱

      ${ } 只在反引號裡有效。用一般引號寫 "${item}"，印出來就是原封不動的 ${item} 這幾個字。

      數字遇到字串的陷阱

      JavaScript
      console.log(1 + 2);
console.log("1" + 2);
console.log("1" + 2 + 3);
console.log(1 + 2 + "3");
      輸出
      3
12
123
33

      這是 JavaScript 最有名的陷阱。+ 的兩邊只要有一邊是字串，就變成「接起來」：

      程式一步一步結果
      "1" + 2左邊是字串 → 接起來"12"
      "1" + 2 + 3由左往右："1" + 2 得 "12"（字串），"12" + 3 再接 → "123""123"
      1 + 2 + "3"由左往右：1 + 2 都是數字得 3，3 + "3" 有字串 → 接起來"33"

      為什麼要特別注意？因為從輸入框拿到的值都是字串，就算使用者打的是數字也一樣（第 7 章會遇到）。拿到 "60" 直接 + 120，得到的是 "60120" 而不是 180。這時要先用 Number() 把字串轉成數字：

      JavaScript
      const input = "60";
console.log(input + 120);
console.log(Number(input) + 120);
      輸出
      60120
180

      減、乘、除就沒有這個問題，因為字串沒有「相減」的意思，JavaScript 會自動把字串轉成數字再算。例如 "10" - 2 得 8。只有 + 兩種意思都有，所以容易出錯。

      字串的長度

      JavaScript

console.log(word.length);
      輸出
      5

      .length 是字串有幾個字。中文、英文、空白、符號，一個字都算 1。

      3.5 資料的型別

      到目前為止看過數字和字串，JavaScript 裡的每個值都有一個型別（type），代表它是哪一種資料。用 typeof 可以查：

      JavaScript
      console.log(typeof 60);
console.log(typeof "60");
console.log(typeof true);
let x;
console.log(typeof x);
console.log(x);
      輸出
      number
string
boolean
undefined
undefined
      型別是什麼例子
      number數字（整數和小數都是）60、3.5、-10
      string字串"早餐"、"60"
      boolean布林：只有「是」和「否」兩個值true、false
      undefined「還沒有值」宣告了變數但沒放東西進去
      null「刻意設定成沒有值」let selected = null;

      注意 60 和 "60" 型別不同：一個是數字，一個是字串。上一節的陷阱就是因為這個。

      boolean 只有 true（真、是）和 false（假、否）兩個值，不用加引號。它用來表示「是不是」，例如「有沒有付款」、「金額是否大於 100」，第 4 章的判斷全靠它。

      let x; 只宣告、沒有放值，x 就是 undefined。null 則是你自己主動放進去、表示「目前沒有」的值，例如「使用者還沒選任何項目」。兩個都代表「沒有」，差在一個是還沒設定，一個是刻意設成空。

      輸出
      NaN
NaN

      把不是數字的字串轉成數字，或拿它去做乘法，會得到 NaN（Not a Number，不是數字）。它的型別卻是 number，很諷刺。程式算出 NaN，通常代表某個地方拿到了不是數字的東西，要往前找是哪個值出了問題。

      3.6 看懂錯誤訊息

      程式出錯時，Console 會出現紅字。初學時最常見的是下面三種，學會看它們能省下很多時間。

      ReferenceError：找不到這個名字

      JavaScript
      const lunch = 120;
console.log(lunh);
      輸出
      Uncaught ReferenceError: lunh is not defined

      「lunh 沒有被定義」。通常是名字拼錯（這裡少了 c），或大小寫不對，或忘了宣告。錯誤訊息會直接告訴你是哪個名字。

      TypeError：對這種資料做了不能做的事

      3.2 節的「對 const 變數重新指定」就是一種 TypeError。另一個常見的情況是對 undefined 或 null 取東西：

      JavaScript
      let item;
console.log(item.length);
      輸出
      Uncaught TypeError: Cannot read properties of undefined (reading 'length')

      「不能讀取 undefined 的屬性（正在讀 length）」。item 沒有值，是 undefined，你卻想拿它的 .length。之後學了物件和從後端拿資料，這會是你最常看到的錯誤：資料還沒拿到，就想讀它裡面的東西。

      SyntaxError：文法錯誤

      JavaScript
      console.log("早餐");
console.log("午餐";
      輸出
      Uncaught SyntaxError: missing ) after argument list

      「參數清單後面少了 )」。第二行的括號沒有關。注意第一行的「早餐」也沒有印出來：文法錯誤是在程式開始執行前就被發現的，整段程式一行都不會跑。這跟前兩種不同，ReferenceError 和 TypeError 是跑到那一行才出錯，前面的已經執行了。

      錯誤什麼時候發生前面的程式有沒有跑常見原因
      SyntaxError執行前沒有，整段都不跑括號、引號沒關，全形符號
      ReferenceError跑到那一行有名字拼錯、沒宣告
      TypeError跑到那一行有改 const、對 undefined 取屬性

      在真正的瀏覽器 Console 裡，紅字的最右邊還會寫出錯在哪個檔案的第幾行，點下去會直接跳到那一行。

      重點

      看到紅字不要慌，先讀錯誤的種類（冒號前面）和訊息（冒號後面），再看是第幾行。錯誤訊息是在幫你，不是在罵你。

      3.7 本章整理

      • JavaScript 寫在 <script> 裡，由上往下一行一行執行。console.log(…) 把結果印到 Console。註解用 // 或 /* */。
      • 變數：const 不能重新指定（預設用它），let 可以。改值時不要再寫 let。= 是「把右邊放進左邊」，先算右邊。
      • 變數名稱用英文、不能數字開頭、不能有空白和 -，大小寫不同。習慣用 camelCase。
      • 計算：+ - * /，% 是餘數，先乘除後加減。簡寫：+=、-=、++、--。小數會有誤差，顯示用 .toFixed()。
      • 字串用引號包起來。+ 會把字串接起來；+ 兩邊只要有一個是字串就變成接起來。從輸入框拿到的都是字串，要用 Number() 轉。
      • 樣板字串用反引號，裡面用 ${ } 放變數或計算。
      • 型別：number、string、boolean（true/false）、undefined（還沒有值）、null（刻意設成空）。typeof 可以查。算出 NaN 代表拿到了不是數字的東西。
      • 錯誤：SyntaxError（文法錯，整段不跑）、ReferenceError（名字找不到）、TypeError（對資料做了不能做的事）。

      上一章的程式都是從第一行跑到最後一行，每行都會執行。這一章讓程式學會「看情況」：條件成立才做某件事，或把同一件事重複做很多次。念完你會：比較兩個值、用 if 做判斷、用 &&、|| 組合條件、看懂 Vue 裡常見的 ? : 寫法，以及用 for、while 重複執行。

      4.7 本章整理

      • 比較的結果是 true 或 false。相等用 ===、不相等用 !==，不要用 ==。一個 = 是放進去，不是比較。
      • if (條件) { … }；else 是否則；else if 由上往下檢查，碰到第一個成立的就進去，後面全部跳過。
      • && 兩邊都要成立，|| 一邊成立就好，! 反過來。
      • falsy 只有六個：false、0、""、null、undefined、NaN，其他都是 truthy。if (note) 可以檢查有沒有填。
      • 三元運算子 條件 ? A : B 是一行的二選一，Vue 畫面裡很常見。
      • for (起點; 條件; 更新)：起點跑一次，每圈開始前檢查條件，每圈結束後更新。累加用的變數要放在迴圈外面。
      • while (條件) 適合不知道要跑幾圈的情況。小心無窮迴圈。
      • break 結束整個迴圈，continue 跳過這一圈。

      • 呼叫（第 7、9 行）：寫 showHeader()，程式才會跳進函式裡，把那三行執行一遍，再回到原本的地方繼續往下。

      上面的 showHeader 每次都做一模一樣的事。如果希望它每次處理不同的資料，就要用參數（parameter）：

      JavaScript

      陷阱

      參數是照順序對應的，跟名字無關。寫成 showItem(60, "早餐")，name 會拿到 60、price 會拿到 "早餐"，印出「60：早餐 元」。

      5.6 把函式交給別人

      在 JavaScript 裡，函式也是一種值，跟數字、字串一樣可以放進變數，也可以當成參數傳給另一個函式。這聽起來很抽象，但它是下一章和 Vue 最重要的基礎之一。

      JavaScript
      function repeat(times, action) {
    for (let i = 1; i <= times; i++) {
        action(i);
    }
}

repeat(3, (n) => {
    console.log(`第 ${n} 次`);
});
      輸出
      第 1 次
第 2 次
第 3 次

      一步一步看：

      1. 呼叫 repeat(3, …)，第一個參數 times 是 3，第二個參數 action 是我們寫的那個箭頭函式。
      2. repeat 裡跑迴圈，每一圈呼叫 action(i)，也就是呼叫我們給它的那個函式，把 i 傳進去。
      3. 我們的函式收到 n，印出「第 n 次」。

      repeat 負責「重複幾次」，我們負責「每次要做什麼」。這種交給別人、讓別人在適當時機呼叫的函式，叫做回呼函式（callback）。

      你很快就會一直用到它：

      • 第 6 章：陣列的 map、filter，你給它一個函式，它對每一筆資料呼叫一次。
      • 第 7 章：按鈕被點下去時要做什麼，你給瀏覽器一個函式，使用者點的時候瀏覽器才呼叫它。
      • 第 13 章：Vue 的 computed、watch，都是給 Vue 一個函式。
      陷阱

      把函式交出去時，傳的是函式本身，不要加小括號。repeat(3, sayHi) 是把 sayHi 這個函式交出去；repeat(3, sayHi()) 是先呼叫 sayHi，把它的結果（字串 "你好"）交出去，repeat 拿到的就不是函式了。

      5.7 本章整理

      • function 名字(參數) { … } 定義函式，定義時不執行；名字(…) 呼叫才執行。呼叫一定要加小括號。
      • 參數照順序對應。少給的是 undefined，多給的被忽略。price = 0 可以設預設值。
      • return 值; 把結果交給呼叫的地方，函式立刻結束。沒有 return 的函式，結果是 undefined。console.log 只是印給人看，程式拿不到。
      • let、const 只在宣告它的大括號裡看得到。裡面看得到外面，外面看不到裡面。
      • 箭頭函式：const f = (a) => { return …; }。只有一行 return 可以寫成 (a) => …；一個參數可省小括號，沒參數不能省。有大括號就要自己寫 return。
      • 函式可以當成值傳給另一個函式（回呼函式）。傳函式本身不加小括號，加了就變成傳結果。

      記帳本不會只有一筆帳，而每筆帳也不只一個數字，還有項目、金額、日期。這一章學怎麼存「很多筆資料」和「有好幾個欄位的資料」。念完你會：用陣列存一串資料、用物件存一筆有欄位的資料、把兩者組合成記帳列表，再用 map、filter、find、reduce 處理整份資料。這一章的寫法，在 Vue 程式裡幾乎每一頁都會看到。

      要記一週七天的午餐錢，開七個變數 day1、day2…太麻煩了。陣列（array）可以把很多個值依序放在同一個變數裡：

      JavaScript

3
      寫法意思
      [60, 120, 85]用中括號包起來、逗號隔開，就是一個陣列。裡面的每個值叫一個元素
      prices[0]拿第幾個元素。中括號裡的數字叫索引（index）
      prices.length陣列裡有幾個元素

      索引從 0 開始，不是從 1。第一個是 [0]，第二個是 [1]……最後一個是 [length - 1]。三個元素的陣列，索引是 0、1、2，沒有 [3]。

      6.3 一筆一筆處理：for…of 和 forEach

      第 4 章的 for 迴圈可以搭配索引走過陣列：

      JavaScript
      const prices = [60, 120, 85];

    console.log(prices[i]);
}
      輸出
      60
120
85

      i 從 0 跑到 length - 1，每圈用 prices[i] 拿出一個。這樣寫可以，但要自己管索引，容易寫錯（例如寫成 i <= prices.length 就會多跑一圈拿到 undefined）。

      for…of：最好讀的寫法

      JavaScript
      const prices = [60, 120, 85];
let total = 0;
for (const price of prices) {
    total += price;
}
console.log(total);
      輸出
      265

      for (const price of prices) 念作「對 prices 裡的每一個 price」。每一圈，price 會自動拿到下一個元素：第一圈 60、第二圈 120、第三圈 85，跑完就結束，不用管索引。這裡的 price 名字自己取，習慣用陣列名稱的單數形。

      forEach：交給陣列一個函式

      另一種寫法是第 5 章 5.6 節的「把函式交給別人」：

      JavaScript
      const items = ["早餐", "午餐"];

    console.log(`${index + 1}. ${item}`);
});

      6.6 map、filter、find：處理整份資料

      這三個方法都要你給它一個函式（回呼函式），它們會對每個元素呼叫一次。差別在於最後回傳什麼。

      map：每一筆都轉換，得到新陣列

      JavaScript
      const records = [
    { item: "早餐", amount: 60 },
    { item: "午餐", amount: 120 }
];
const names = records.map((r) => r.item);
console.log(names);
const labels = records.map((r) => `${r.item} ${r.amount} 元`);
console.log(labels);
      輸出
      ["早餐", "午餐"]
["早餐 60 元", "午餐 120 元"]

      map 對每一筆呼叫你的函式，把每次的回傳值收集成一個新陣列。原本有幾筆，新陣列就有幾筆。(r) => r.item 是第 5 章的箭頭函式簡寫，意思是「給我一筆 r，我回傳它的 item」。

      filter：留下符合條件的

      JavaScript
      const records = [
    { item: "早餐", amount: 60, type: "餐飲" },
    { item: "捷運", amount: 35, type: "交通" },
    { item: "午餐", amount: 120, type: "餐飲" }
];
const food = records.filter((r) => r.type === "餐飲");
console.log(food.length);
const big = records.filter((r) => r.amount >= 100);
console.log(big);
      輸出
      2
[{ item: "午餐", amount: 120, type: "餐飲" }]

      filter 對每一筆呼叫你的函式，函式回傳 true 的就留下來，false 的就丟掉，結果是一個新陣列。注意 big 只有一筆，但仍然是陣列（外面有中括號）。

      find：找第一筆符合的

      JavaScript
      const records = [
    { id: 1, item: "早餐" },
    { id: 2, item: "午餐" },
    { id: 3, item: "晚餐" }
];
const r = records.find((r) => r.id === 2);
console.log(r);
console.log(r.item);
console.log(records.find((r) => r.id === 9));
      輸出
      { id: 2, item: "午餐" }
午餐
undefined

      find 跟 filter 很像，但它找到第一筆符合的就停下來，回傳那一筆本身（不是陣列）。都找不到就回傳 undefined。用 id 找某一筆資料時最常用。

      方法你的函式要回傳結果原陣列 3 筆時，結果有幾筆
      map轉換後的值新陣列一定 3 筆
      filtertrue／false新陣列0～3 筆
      findtrue／false一筆元素，或 undefined不是陣列
      重點

      map、filter 都不會改原本的陣列，而是產生一個新的。這個特性在 Vue 裡很重要：Vue 常常需要「從原始資料算出另一份要顯示的資料」（第 13 章的 computed）。

      串起來用

      因為 filter 回傳的還是陣列，可以接著 .map：

      JavaScript
      const records = [
    { item: "早餐", amount: 60, type: "餐飲" },
    { item: "捷運", amount: 35, type: "交通" },
    { item: "午餐", amount: 120, type: "餐飲" }
];
const result = records
    .filter((r) => r.type === "餐飲")
    .map((r) => r.item);
console.log(result);
      輸出
      ["早餐", "午餐"]

      先 filter 留下兩筆餐飲，再 map 取出項目名稱。寫成好幾行，每行一個步驟，比較好讀。

      6.7 加總：reduce

      記帳最常做的事：算總金額。用 6.3 節的 for…of 就能做：

      JavaScript
      const records = [
    { item: "早餐", amount: 60 },
    { item: "捷運", amount: 35 },
    { item: "午餐", amount: 120 }
];
let total = 0;
for (const r of records) {
    total += r.amount;
}
console.log(total);
      輸出
      215

      在 Vue 的程式碼裡，你更常看到用 reduce 寫成一行：

      JavaScript
      const records = [
    { item: "早餐", amount: 60 },
    { item: "捷運", amount: 35 },
    { item: "午餐", amount: 120 }
];
const total = records.reduce((sum, r) => sum + r.amount, 0);
console.log(total);
      輸出
      215

      reduce 比前面三個難懂一點。拆開看：

      部分意思
      (sum, r) => sum + r.amount你的函式。sum 是「到目前為止的累計」，r 是這一筆。回傳值會變成下一次的 sum
      0sum 一開始的值（就像 let total = 0）

      一筆一筆追：

      第幾次呼叫sumr.amount回傳 sum + r.amount
      10（起始值）6060
      2603595
      395120215

      最後一次的回傳值 215，就是 reduce 的結果。它其實就是 for…of 加總的另一種寫法：sum 對應 total，0 對應 let total = 0。看不懂 reduce 時，就在腦中把它翻成 for…of。

      陷阱

      別忘了最後的起始值 0。少了它，reduce 會拿第一筆整個物件當起始的 sum，接著算 物件 + 35，得到一串奇怪的字串。

      6.8 複製和比較：兩個變數指向同一個東西

      陣列和物件有一個很重要、跟數字字串不一樣的特性：

      JavaScript
      let a = 60;
let b = a;
b = 100;
console.log(a);

const list1 = ["早餐"];
const list2 = list1;
list2.push("午餐");
console.log(list1);
      輸出
      60
["早餐", "午餐"]
      • 數字：b = a 是把 a 的值複製一份給 b。之後改 b，a 不受影響，還是 60。
      • 陣列：list2 = list1 不會複製陣列，而是讓 list2 也指向同一個陣列。所以對 list2 push，從 list1 看也多了一筆，因為它們根本是同一個。

      比喻：數字像影印，你在影本上塗鴉，原稿不受影響。陣列和物件像共用一個雲端文件的連結，list2 = list1 只是把連結再傳給另一個人，任何人改了，大家看到的都是改過的。

      真的要複製：...

      要複製出一個獨立的新陣列或物件，用三個點 ...（叫 spread，展開）：

      JavaScript
      const list1 = ["早餐"];
const list2 = [...list1];
list2.push("午餐");
console.log(list1);
console.log(list2);

const r1 = { item: "早餐", amount: 60 };
const r2 = { ...r1, amount: 80 };
console.log(r1);
console.log(r2);
      輸出
      ["早餐"]
["早餐", "午餐"]
{ item: "早餐", amount: 60 }
{ item: "早餐", amount: 80 }

      [...list1] 是「建一個新陣列，把 list1 的元素一個一個展開放進去」。{ ...r1, amount: 80 } 是「建一個新物件，先把 r1 的屬性都放進去，再把 amount 設成 80」。後寫的蓋過先寫的，所以 amount 是 80。原本的 r1 完全沒變。

      比較陣列和物件

      JavaScript
      const a = [1, 2];
const b = [1, 2];
const c = a;
console.log(a === b);
console.log(a === c);
      輸出
      false
true

      === 比較陣列和物件時，比的是「是不是同一個」，不是「內容一不一樣」。a 和 b 內容相同，但是兩個各自建立的陣列，所以不相等；c 跟 a 指向同一個，所以相等。

      重點

      陣列和物件用 = 給另一個變數時，兩個變數指向同一個東西，改一個另一個也會變。要獨立的複本，用 [...陣列] 或 { ...物件 }。

      6.9 本章整理

      • 陣列 [a, b, c]：索引從 0 開始，arr[i] 拿元素，arr.length 是個數，最後一個是 arr[arr.length - 1]，超出範圍得到 undefined。
      • push 加到最後、pop 拿掉最後一個、includes 有沒有、indexOf 在第幾個（找不到 −1）、join 接成字串。
      • const 的陣列、物件可以改內容，但不能整個換掉。
      • 走訪陣列：for (const x of arr) 最好讀；需要索引用 arr.forEach((x, i) => …)。
      • 物件 { key: value }：obj.key 讀、改、新增屬性；讀不存在的屬性得到 undefined。obj["key"] 或 obj[變數] 可以用字串指定屬性名稱。
      • 物件陣列是最常見的資料形狀，每筆用不重複的 id 分辨。
      • map 每筆轉換成新陣列；filter 留下回傳 true 的；find 回傳第一筆符合的（找不到是 undefined）。它們都不改原陣列，可以串起來用。
      • reduce((sum, x) => sum + …, 0) 加總，等於 for…of 累加。別忘了起始值。
      • 陣列、物件用 = 給別人是共用同一個，=== 比的是是不是同一個。複製用 [...arr]、{ ...obj }。

      第 3～6 章的程式都只在 Console 印東西，網頁畫面完全沒變。這一章把 JavaScript 和 HTML 接起來：念完你會用 JavaScript 找到網頁上的元素、改它的文字和樣式、在使用者點按鈕或打字時做事，最後親手做一個小記帳程式。做完之後，你會很清楚地感受到「為什麼需要 Vue」。

      7.1 DOM：瀏覽器把 HTML 變成物件

      瀏覽器讀 HTML 時，會把每個元素都變成一個 JavaScript 的物件（第 6 章），整份網頁就是一棵由物件組成的樹。這棵樹叫做 DOM（Document Object Model，文件物件模型）。開發者工具 Elements 分頁看到的，其實就是 DOM。

      JavaScript 透過一個叫 document 的物件操作 DOM。最常用的是 document.querySelector(…)：給它一個 CSS 選擇器（第 2 章），它回傳第一個符合的元素。

      找到元素、讀它的文字
      <h1 id="title">記帳本</h1>
<p class="note">今天還沒記帳</p>
<p id="result"></p>
<script>
    const title = document.querySelector("#title");
    const note = document.querySelector(".note");
    const result = document.querySelector("#result");
    result.textContent = "標題是「" + title.textContent + "」，備註是「" + note.textContent + "」";
</script>
      畫面
      程式意思
      document.querySelector("#title")找 id 是 title 的元素。括號裡寫法跟 CSS 選擇器一模一樣：# 是 id、. 是 class
      title.textContent這個元素裡面的文字
      result.textContent = "…"把這個元素裡的文字換成新的。畫面會馬上跟著變

      從這一章開始，範例的結果直接顯示在「畫面」上，不再用 console.log。這也是真正做網頁時的樣子：使用者看不到 Console，看得到的只有畫面。

      陷阱

      <script> 要寫在它要找的元素後面，通常放在 <body> 的最後。程式由上往下執行，如果 script 寫在 <h1> 前面，執行時 <h1> 還不存在，querySelector 找不到東西會回傳 null，接著讀 .textContent 就會出現第 3 章的 TypeError。

      找不到時回傳 null。要找所有符合的元素，用 document.querySelectorAll(…)，它回傳一個像陣列的清單，可以用 for…of 一個一個處理。

      7.2 改文字、改樣式

      改文字和樣式
      <style>
    .warn {
        color: white;
        background-color: #e53935;
        padding: 4px 8px;
    }
</style>
<p id="total">合計：0 元</p>
<p id="msg">一切正常</p>
<script>
    const total = document.querySelector("#total");
    const msg = document.querySelector("#msg");
    total.textContent = "合計：3,280 元";
    total.style.fontSize = "24px";
    msg.textContent = "本月超支了";
    msg.classList.add("warn");
</script>
      畫面
      寫法做什麼
      元素.textContent = "…"換掉裡面的文字
      元素.style.fontSize = "24px"直接設定樣式，等於第 2 章的 style 屬性。CSS 的 font-size 在這裡要寫成 camelCase 的 fontSize（因為 - 會被當成減號）
      元素.classList.add("warn")替元素加上一個 class
      元素.classList.remove("warn")拿掉一個 class
      元素.classList.toggle("warn")有就拿掉、沒有就加上

      改樣式比較好的做法是用 classList：樣式先在 CSS 裡寫好（.warn），JavaScript 只負責「加上或拿掉 class」。這樣外觀歸 CSS、行為歸 JavaScript，分工清楚。直接改 style 適合少數真的要算出來的值，例如進度條的寬度。

      textContent 和 innerHTML

      還有一個 innerHTML，它會把字串當成 HTML 來解讀：

      HTML
      <p id="a"></p>
<p id="b"></p>
<script>
    document.querySelector("#a").textContent = "<strong>粗體</strong>";
    document.querySelector("#b").innerHTML = "<strong>粗體</strong>";
</script>
      畫面

      第一行原封不動顯示了標籤，第二行則真的變成粗體。innerHTML 看起來比較強大，但如果放進去的字串是使用者輸入的，使用者就能在你的網頁裡塞進任何 HTML，甚至可以偷偷執行程式的標籤，這是很常見的資安漏洞。顯示使用者輸入的文字時，一律用 textContent。好消息是 Vue 的 {{ }} 預設就是 textContent 的行為，會自動幫你擋掉這個問題。

      7.3 事件：使用者做了什麼就做事

      到目前為止，程式都是網頁一打開就跑完。要在使用者點按鈕的時候才做事，要替按鈕註冊一個事件（event）：

      計數器
      <p>今天喝了 <span id="count">0</span> 杯水</p>
<button id="add">喝一杯</button>
<script>
    const countEl = document.querySelector("#count");
    const addBtn = document.querySelector("#add");
    let count = 0;

    addBtn.addEventListener("click", () => {
        count++;
        countEl.textContent = count;
    });
</script>
      畫面

      在上面的畫面按幾下「喝一杯」，數字會跟著加。拆開 addBtn.addEventListener("click", () => { … })：

      部分意思
      addBtn要監聽哪個元素
      addEventListener「加上一個事件監聽器」：開始注意這個元素發生的事
      "click"要注意哪一種事件：點擊
      () => { … }事件發生時要執行的函式

      這就是第 5 章 5.6 節的「把函式交給別人」：我們把函式交給瀏覽器，使用者每點一次，瀏覽器就呼叫一次這個函式。網頁打開時，這個函式一次都還沒執行。

      每次點擊，函式做兩件事：count++ 改資料，countEl.textContent = count 把新的資料顯示到畫面上。兩件事都要做，少了第二步，count 雖然變了，畫面卻停在 0。這件事在 7.6 節很重要。

      陷阱

      let count = 0; 要寫在事件函式的外面。寫在函式裡面的話，每點一次都會重新建一個從 0 開始的 count，按再多下都只會顯示 1（第 5 章 5.4 節的作用域）。

      常用的事件

      事件什麼時候發生
      click點擊
      input輸入框的內容每改變一次（每打一個字）
      change輸入框改完、離開時；下拉選單選了別的；勾選框勾或取消
      keydown按下鍵盤的鍵
      submit表單送出

      7.4 讀取輸入框

      輸入框的內容用 .value 讀取：

      輸入名字
      <input id="name" placeholder="你的名字">
<button id="hi">打招呼</button>
<p id="out"></p>
<script>
    const nameInput = document.querySelector("#name");
    const out = document.querySelector("#out");
    document.querySelector("#hi").addEventListener("click", () => {
        const name = nameInput.value;
        if (name === "") {
            out.textContent = "請先輸入名字";
        } else {
            out.textContent = `你好，${name}！`;
        }
    });
</script>
      畫面

      注意 nameInput.value 是寫在事件函式裡面。如果在函式外面、網頁一打開就讀，那時使用者還沒打字，讀到的永遠是空字串。要在「按下按鈕的那一刻」才去讀，才會拿到使用者打的內容。

      value 一定是字串

      第 3 章說過「從輸入框拿到的值都是字串」，現在親眼看看：

      加總兩個金額
      <input id="a" type="number" value="60">
<input id="b" type="number" value="120">
<button id="sum">加起來</button>
<p id="wrong"></p>
<p id="right"></p>
<script>
    document.querySelector("#sum").addEventListener("click", () => {
        const a = document.querySelector("#a").value;
        const b = document.querySelector("#b").value;
        document.querySelector("#wrong").textContent = "直接加：" + (a + b);
        document.querySelector("#right").textContent = "轉成數字再加：" + (Number(a) + Number(b));
    });
</script>
      畫面

      按下「加起來」：直接加得到 60120，轉成數字才是 180。就算是 type="number" 的輸入框，.value 拿到的仍然是字串，只是瀏覽器限制使用者只能打數字而已。

      input 事件：邊打邊更新

      即時預覽
      <input id="item" placeholder="項目">
<p>預覽：<span id="preview">（空白）</span></p>
<script>
    const item = document.querySelector("#item");
    const preview = document.querySelector("#preview");
    item.addEventListener("input", () => {
        preview.textContent = item.value || "（空白）";
    });
</script>
      畫面

      在輸入框打字，下面的預覽會每打一個字就更新一次。item.value || "（空白）" 用了第 4 章的 ||：|| 其實會回傳「第一個 truthy 的值」，item.value 是空字串（falsy）時，就改用後面的「（空白）」。這是 JavaScript 很常見的「給預設值」寫法。

      7.5 做一個小記帳程式

      把學過的組起來：輸入項目和金額、按新增，下面的列表和合計就會更新。程式比較長，先看畫面玩玩看，再一段一段讀：

      小記帳程式（沒有 Vue 的版本）
      <style>
    li { display: flex; justify-content: space-between; max-width: 260px; }
</style>
<input id="item" placeholder="項目">
<input id="amount" type="number" placeholder="金額">
<button id="add">新增</button>
<ul id="list"></ul>
<p>合計：<span id="total">0</span> 元</p>
<script>
    // 資料
    const records = [
        { id: 1, item: "早餐", amount: 60 }
    ];
    let nextId = 2;

    // 找到要用的元素
    const itemInput = document.querySelector("#item");
    const amountInput = document.querySelector("#amount");
    const list = document.querySelector("#list");
    const totalEl = document.querySelector("#total");

    // 依照 records 重新畫出列表和合計
    function render() {
        list.innerHTML = "";
        for (const r of records) {
            const li = document.createElement("li");
            const name = document.createElement("span");
            const money = document.createElement("span");
            name.textContent = r.item;
            money.textContent = r.amount;
            li.append(name, money);
            list.append(li);
        }
        const total = records.reduce((sum, r) => sum + r.amount, 0);
        totalEl.textContent = total;
    }

    // 按下新增
    document.querySelector("#add").addEventListener("click", () => {
        const item = itemInput.value;
        const amount = Number(amountInput.value);
        if (item === "" || amount <= 0) {
            return;
        }
        records.push({ id: nextId, item: item, amount: amount });
        nextId++;
        itemInput.value = "";
        amountInput.value = "";
        render();
    });

    render();
</script>
      畫面

      程式分成四塊：

      區塊做什麼
      資料records 是第 6 章的物件陣列，存所有記帳。nextId 是下一筆要用的 id
      找元素用 querySelector 先把要用的元素找好，存進變數
      render()「依照目前的 records，把畫面重畫一遍」：先清空列表，再一筆一筆建立 li 放進去，最後算合計
      新增按鈕讀輸入框 → 檢查（沒填項目或金額不大於 0 就 return 不做事，第 5 章的提早 return）→ push 進 records → 清空輸入框 → 呼叫 render()

      render 裡用到兩個新東西：

      • document.createElement("li")：建立一個新的 li 元素。剛建立時它還不在畫面上，只存在 JavaScript 裡。
      • 元素.append(…)：把元素放進另一個元素裡面（放在最後）。list.append(li) 之後，li 才真的出現在畫面上。

      最後一行 render(); 是網頁一打開先畫一次，不然原本的「早餐」不會出現。

      7.6 為什麼需要 Vue

      上面的記帳程式能用，但寫起來有很多麻煩。想像一下要再加這些功能：刪除某一筆、編輯金額、依分類篩選、顯示「本月超支」的警告……每一個功能都要：

      1. 改資料（records）。
      2. 記得呼叫 render()，或自己去找到對應的元素改它的文字。

      第 2 步就是問題所在。資料和畫面是兩份東西，每次改資料都要手動讓畫面跟上。程式一大，總會有某個地方忘了更新畫面，結果資料是對的、畫面是錯的，這種錯誤很難找。7.3 節的計數器，如果漏了 countEl.textContent = count; 這一行，按鈕看起來就像壞了一樣。

      另外，render() 每次都把整個列表清空重建，資料一多就很浪費；而且畫面長什麼樣子，散落在 createElement、textContent 這些程式裡，很難一眼看出來。

      自己操作 DOM（這一章）Vue（下一章起）
      畫面長怎樣藏在 JavaScript 裡一行一行組出來直接寫成 HTML，一眼就看得出來
      資料改了要自己記得更新畫面畫面自動跟著變
      你負責的事改資料 ＋ 改畫面只要改資料

      先偷看一下，7.3 節的計數器用 Vue 寫會長這樣（第 8～10 章會一行一行教）：

      HTML
      <div id="app">
    <p>今天喝了 {{ count }} 杯水</p>
    <button @click="count++">喝一杯</button>
</div>

      畫面就是 HTML，{{ count }} 的地方會顯示 count 的值；按鈕被點時 count++。沒有 querySelector，也沒有 textContent = …：count 一變，畫面上的數字自己就會更新。這就是 Vue 最核心的價值。

      重點

      自己操作 DOM 時，你要同時管「資料」和「畫面」。Vue 讓你只管資料，畫面依照資料自動更新。這一章學的 DOM 和事件觀念，是理解 Vue 在幫你做什麼的基礎。

      7.7 本章整理

      • DOM 是瀏覽器把 HTML 變成的物件樹。document.querySelector("CSS 選擇器") 找第一個符合的元素，找不到是 null；querySelectorAll 找全部。
      • <script> 要放在它要找的元素後面，通常在 <body> 最後。
      • textContent 讀或換掉文字。innerHTML 會把字串當 HTML，不要用它顯示使用者輸入的內容。
      • 改樣式：style.屬性（camelCase），或更好的 classList.add / remove / toggle。
      • 元素.addEventListener("事件", 函式)：事件發生時瀏覽器呼叫你的函式。常用事件：click、input、change。
      • 輸入框用 .value 讀，要在事件函式裡讀才拿得到使用者打的內容；.value 一定是字串。
      • document.createElement 建立元素，append 放進畫面。
      • 自己操作 DOM，每次改資料都要記得更新畫面；Vue 讓畫面自動跟著資料變。

      終於要開始用 Vue 了。這一章做最基本的一件事：把 JavaScript 裡的資料顯示到畫面上。念完你會：把 Vue 加進網頁、看懂 createApp、setup、mount 每一行在做什麼、用 {{ }} 顯示資料，以及看到畫面不對時該從哪裡找原因。資料改了畫面自動更新的部分，是下一章的主題。

      8.1 把 Vue 加進網頁

      Vue 是別人寫好的一大段 JavaScript。最簡單的用法，是用 <script src="…"> 從網路上載入它：

      HTML
      <script src="https://cdnjs.cloudflare.com/ajax/libs/vue/3.5.13/vue.global.js"></script>

      <script> 加上 src 屬性，意思是「到這個網址下載 JavaScript 檔案來執行」，跟第 1 章 <img src> 載入圖片的概念一樣。網址裡的 3.5.13 是 Vue 的版本號。這種放在網路上、讓大家直接引用的檔案伺服器叫做 CDN。

      載入之後，網頁裡就多了一個叫 Vue 的物件，Vue 的所有功能都在它裡面。

      重點

      書裡的 Vue 範例標題會寫「Vue」，書會自動幫你在最前面加上這一行 <script src>，所以範例程式碼裡看不到它。你自己存成檔案時，一定要記得加，而且要放在你自己的 <script> 前面，因為要先載入 Vue，才能使用它。

      這種直接用 <script src> 載入的方式，適合學習和小網頁。第 15 章會改用正式專案的做法。但不管用哪種方式，Vue 本身的寫法都一樣，這幾章學的東西到時候都用得上。

      8.2 第一個 Vue 程式

      第一個 Vue 程式
      <div id="app">
    <h1>{{ title }}</h1>
    <p>早餐花了 {{ breakfast }} 元</p>
</div>

<script>
    const { createApp } = Vue;

    createApp({
        setup() {
            const title = "我的記帳本";
            const breakfast = 60;
            return { title, breakfast };
        }
    }).mount("#app");
</script>
      畫面

      畫面上 {{ title }} 變成了「我的記帳本」，{{ breakfast }} 變成了 60。程式碼看起來有點多，一段一段拆開。

      HTML 的部分：模板

      <div id="app"> 裡面的 HTML 叫做模板（template），也就是「畫面長這樣，{{ }} 的地方要填資料」。{{ title }} 的意思是：「這裡顯示 title 的值」。雙大括號長得像兩撇鬍子，所以常被叫做 mustache（八字鬍）語法。

      JavaScript 的部分

      程式意思
      const { createApp } = Vue;從 Vue 物件裡拿出 createApp 這個函式（寫法見下面說明）
      createApp({ … })建立一個 Vue 應用程式。括號裡傳進一個物件，描述這個應用程式
      setup() { … }物件裡的一個函式，Vue 會在開始時呼叫它一次。在這裡準備要給畫面用的資料
      return { title, breakfast };把資料交給模板。只有 return 出去的東西，模板才看得到
      .mount("#app")把這個應用程式「掛」到 id="app" 的元素上。從此這個元素裡面由 Vue 負責

      兩個新寫法

      這段程式用到兩個第 6 章沒教的物件寫法，它們只是簡寫：

      簡寫完整寫法意思
      const { createApp } = Vue;const createApp = Vue.createApp;從物件裡拿出同名的屬性，放進同名的變數。叫做解構（destructuring）。要拿好幾個就用逗號隔開：const { createApp, ref } = Vue;
      return { title, breakfast };return { title: title, breakfast: breakfast };屬性名稱和變數名稱一樣時，可以只寫一次
      setup() { … }setup: function () { … }物件裡的函式可以省略 : function

      這三種簡寫在 Vue 的程式裡到處都是，一定要看得懂。

      JavaScript
      const record = { item: "早餐", amount: 60 };
const { item, amount } = record;
console.log(item, amount);

const title = "記帳本";
const app = { title };
console.log(app);
      輸出
      早餐 60
{ title: "記帳本" }
      重點

      Vue 程式的骨架：createApp({ setup() { …準備資料… return { …交給畫面… }; } }).mount("#app")。資料要 return 出去，模板才看得到。

      8.3 mount 的範圍

      Vue 只管理 mount 指定的那個元素裡面。外面的 {{ }} 它不會處理：

      範圍外的 {{ }}
      <p>外面：{{ title }}</p>
<div id="app">
    <p>裡面：{{ title }}</p>
</div>

<script>
    const { createApp } = Vue;
    createApp({
        setup() {
            const title = "記帳本";
            return { title };
        }
    }).mount("#app");
</script>
      畫面

      第一行在 #app 外面，{{ title }} 原封不動地顯示出來，因為對瀏覽器來說它就只是普通的文字。第二行在 #app 裡面，Vue 才把它換成資料。

      所以一般的做法是：整個頁面要用 Vue 的部分，全部包在同一個 <div id="app"> 裡。

      陷阱

      mount("#app") 裡的 # 不能漏。它跟 querySelector 一樣是 CSS 選擇器，寫成 mount("app") 會去找 <app> 這種標籤，找不到，Vue 就什麼都不做，畫面上會看到一堆原封不動的 {{ }}。

      8.4 {{ }} 裡可以寫什麼

      {{ }} 裡不只能放變數名稱，還可以放任何「會算出一個值」的 JavaScript，這種東西叫運算式（expression）：

      {{ }} 裡的運算式
      <div id="app">
    <p>兩份：{{ price * 2 }} 元</p>
    <p>含稅：{{ (price * 1.05).toFixed(0) }} 元</p>
    <p>{{ price > 100 ? "有點貴" : "還好" }}</p>
    <p>{{ `${item}：${price} 元` }}</p>
    <p>項目有 {{ item.length }} 個字</p>
</div>

<script>
    const { createApp } = Vue;
    createApp({
        setup() {
            const item = "牛肉麵";
            const price = 150;
            return { item, price };
        }
    }).mount("#app");
</script>
      畫面

      計算、呼叫方法（.toFixed）、第 4 章的三元運算子、第 3 章的樣板字串、讀屬性（.length），全都可以。

      但是不能寫敘述（statement），也就是 if、for、let 這種「做一件事」而不是「算出一個值」的程式：

      HTML
      <!-- 這些都不行 -->
<p>{{ let x = 1 }}</p>
<p>{{ if (price > 100) { "貴" } }}</p>
      運算式（可以）敘述（不行）
      會算出一個值，可以放在 = 右邊做一件事，不會算出值
      price * 2、a > b ? "x" : "y"、item.lengthlet x = 1、if (…) { … }、for (…) { … }

      判斷一個東西能不能放進 {{ }}，就問：它能不能放在 const x = ___ 的右邊？能的話就是運算式。這也是第 4 章說三元運算子在 Vue 裡很常見的原因。至於「條件成立才顯示一整塊」和「重複顯示很多筆」，Vue 有專門的寫法，第 11 章會教。

      陷阱

      {{ }} 裡的東西會被當成純文字顯示（跟第 7 章的 textContent 一樣）。就算值是 "<strong>粗</strong>"，畫面上也會原封不動顯示標籤，不會變粗體。這是 Vue 替你擋掉資安問題的設計。

      8.5 顯示物件和陣列，以及給畫面用的函式

      第 6 章的物件和陣列也可以交給模板，用點和中括號讀裡面的值：

      物件和陣列
      <div id="app">
    <p>{{ record.item }}：{{ record.amount }} 元</p>
    <p>第一個分類是 {{ types[0] }}，共 {{ types.length }} 種</p>
    <p>備註：{{ record.note }}</p>
</div>

<script>
    const { createApp } = Vue;
    createApp({
        setup() {
            const record = { item: "早餐", amount: 60 };
            const types = ["餐飲", "交通", "其他"];
            return { record, types };
        }
    }).mount("#app");
</script>
      畫面

      注意第三行：record 沒有 note 屬性，record.note 是 undefined。Vue 遇到 undefined 和 null 會顯示成空白，不會顯示「undefined」這幾個字。

      把函式交給畫面

      setup 裡也可以定義函式、return 出去，在模板裡呼叫。重複的顯示格式很適合這樣做：

      格式化金額的函式
      <div id="app">
    <p>早餐 {{ money(60) }}</p>
    <p>房租 {{ money(12000) }}</p>
</div>

<script>
    const { createApp } = Vue;
    createApp({
        setup() {
            const money = (n) => "NT$ " + n.toLocaleString();
            return { money };
        }
    }).mount("#app");
</script>
      畫面

      n.toLocaleString() 會把數字加上千分位逗號，12000 變成 12,000。模板裡的 money(60) 是一般的函式呼叫，回傳值會顯示在那個位置。

      8.6 畫面不對時怎麼找原因

      Vue 的錯誤，有時候畫面只是「怪怪的」，不會有明顯的紅字。下面是初學最常遇到的幾種情況：

      你看到的畫面最可能的原因
      一堆原封不動的 {{ title }}Vue 沒有啟動：①忘了載入 Vue，或載入的 <script src> 寫在自己的程式後面 ②mount 的選擇器錯了（漏了 #、id 拼錯）③那段 {{ }} 在 #app 外面 ④JavaScript 有錯，程式根本沒跑到 mount
      某個 {{ }} 的地方是空白①忘了在 setup 裡 return 它 ②模板和 return 的名稱拼得不一樣 ③它的值是 undefined（例如屬性名稱拼錯）
      整個 #app 變成空白模板裡的運算式出錯了，例如讀 undefined 的屬性

      看下面這個例子，breakfast 忘了 return：

      忘了 return
      <div id="app">
    <p>標題：{{ title }}</p>
    <p>早餐：{{ breakfast }} 元</p>
</div>

<script>
    const { createApp } = Vue;
    createApp({
        setup() {
            const title = "記帳本";
            const breakfast = 60;
            return { title };
        }
    }).mount("#app");
</script>
      畫面

      畫面上「早餐」後面是空白，沒有任何錯誤訊息出現在畫面上。這時打開開發者工具的 Console，會看到 Vue 留下的黃色警告（warning）：

      [Vue warn]: Property "breakfast" was accessed during render but is not defined on instance.

      意思是：「畫面用到了 breakfast，但是 Vue 找不到它」。看到這個警告，就去檢查 setup 有沒有 return 它、名稱有沒有拼錯。

      重點

      畫面不對時，第一件事一樣是打開 Console。紅色是錯誤，黃色的 [Vue warn] 是 Vue 給你的提示，通常會直接說出是哪個名字有問題。書裡範例畫面的訊息，也會出現在這本書所在分頁的 Console 裡。

      其他常見的警告：mount 的選擇器寫錯時是 Failed to mount app: mount target selector "app" returned null.（找不到要掛上去的元素）；模板裡的運算式出錯時是 Unhandled error during execution of render function，後面還會跟著一行紅色的錯誤，例如 Cannot read properties of undefined。

      書裡範例載入的是 Vue 的「開發版」，會顯示這些警告。正式上線的網站用「正式版」（檔名有 prod），檔案比較小，但不會顯示警告。學習時一定要用開發版。

      8.7 本章整理

      • 用 <script src="…vue.global.js"> 載入 Vue，要放在自己的程式前面。載入後有一個 Vue 物件。
      • 骨架：createApp({ setup() { …; return { … }; } }).mount("#app")。setup 只會被呼叫一次，只有 return 出去的東西模板才看得到。
      • 簡寫：const { a } = obj（解構）、{ title } 等於 { title: title }、setup() {} 等於 setup: function () {}。
      • Vue 只管 mount 的元素裡面，外面的 {{ }} 會原樣顯示。
      • {{ }} 裡可以放任何運算式（能放在 = 右邊的），不能放 if、for、let 這種敘述。內容會當成純文字顯示。
      • undefined、null 在畫面上顯示成空白。
      • 畫面不對先看 Console：[Vue warn] … is not defined 通常是忘了 return 或名稱拼錯；一堆原樣的 {{ }} 代表 Vue 沒啟動。

      上一章的資料只會在一開始顯示一次。這一章學 Vue 最核心的功能：資料一改，畫面自動跟著變。念完你會：知道為什麼普通變數做不到、用 ref 建立會通知畫面的資料、搞清楚什麼時候要寫 .value，以及讓物件和陣列也能自動更新。第 7 章結尾說的「Vue 讓你只管資料」，就是從這一章開始。

      9.1 普通變數改了，畫面不會變

      這一章需要一個「改資料」的方法。我們先借用第 10 章才會細講的寫法：在按鈕上寫 @click="函式名稱"，按鈕被點時，Vue 就會呼叫 setup 裡 return 出去的那個函式。現在只要知道這樣用就好。

      用普通變數做計數器（不會動）
      <div id="app">
    <p>今天喝了 {{ count }} 杯水</p>
    <button @click="add">喝一杯</button>
</div>

<script>
    const { createApp } = Vue;
    createApp({
        setup() {
            let count = 0;
            const add = () => {
                count++;
                console.log("count 現在是", count);
            };
            return { count, add };
        }
    }).mount("#app");
</script>
      畫面

      按幾下「喝一杯」，畫面上的數字一直是 0。如果打開開發者工具的 Console，會看到 count 現在是 1、2、3……資料確實在變，畫面卻沒跟上。

      原因是：return { count, add } 交給模板的，是 count 當時的值 0。第 6 章 6.8 節說過，數字是「影印」：模板拿到的是一份影本，之後 count++ 改的是 setup 裡的原稿，影本不會變。而且就算 Vue 拿得到新的值，它也不知道 count 什麼時候變了，不會去重畫。

      要讓畫面跟著變，Vue 需要兩件事：拿得到最新的值，而且值一變就有人通知它。ref 就是做這件事的。

      9.2 ref：會通知畫面的盒子

      用 ref 做計數器
      <div id="app">
    <p>今天喝了 {{ count }} 杯水</p>
    <button @click="add">喝一杯</button>
</div>

<script>
    const { createApp, ref } = Vue;
    createApp({
        setup() {
            const count = ref(0);
            const add = () => {
                count.value++;
            };
            return { count, add };
        }
    }).mount("#app");
</script>
      畫面

      現在按「喝一杯」，數字會跟著加了。跟上一個範例比，只改了三個地方：

      改了什麼意思
      const { createApp, ref } = Vue;多從 Vue 拿出 ref 這個函式
      const count = ref(0);不直接存 0，而是用 ref(0) 建立一個「裝著 0 的盒子」
      count.value++;盒子裡的值放在 .value，要改的是 .value

      ref 建立的是一個物件，值放在它的 value 屬性裡。因為是物件，模板拿到的跟 setup 裡的是同一個盒子（第 6 章 6.8 節：物件是共用的，不是影印），所以拿得到最新的值。而且這個盒子很特別：每次有人改 .value，它都會通知 Vue，Vue 就會去更新用到它的畫面。

      這種「資料改了會自動通知畫面」的特性，叫做響應式（reactive）。用 ref 建立的資料，就叫響應式資料。

      重點

      想讓畫面跟著資料變，就用 ref(初始值) 建立資料。這是 Vue 最核心的一件事。

      注意 count 用的是 const。我們從來不把 count 換成別的東西，只改盒子裡的 .value，所以用 const 完全沒問題（第 6 章：const 的物件可以改內容）。

      9.3 什麼時候要寫 .value

      剛學 ref 時最容易搞混的就是 .value。規則只有一條：

      在哪裡要不要寫 .value例子
      JavaScript（setup 裡）要count.value++、console.log(count.value)
      模板（HTML 裡）不用，Vue 會自動幫你拿出 .value{{ count }}、{{ count * 2 }}
      模板裡不用寫 .value
      <div id="app">
    <p>{{ count }} 杯，{{ count * 250 }} 毫升</p>
    <p>{{ count >= 8 ? "喝夠了" : "再多喝一點" }}</p>
    <button @click="add">喝一杯</button>
</div>

<script>
    const { createApp, ref } = Vue;
    createApp({
        setup() {
            const count = ref(7);
            const add = () => {
                count.value++;
            };
            return { count, add };
        }
    }).mount("#app");
</script>
      畫面

      按一下「喝一杯」，三個地方會同時更新：杯數、毫升數、提示文字。只要模板裡用到 count 的地方，Vue 都會幫你重新計算。

      忘了 .value 會怎樣

      在 JavaScript 裡忘了寫 .value，是最常見的錯誤：

      JavaScript
      const count = { value: 0 };   // 模擬 ref(0) 的樣子
console.log(count);
console.log(count.value);
console.log(count + 1);
count++;
      輸出
      { value: 0 }
0
[object Object]1
Uncaught TypeError: Assignment to constant variable.

      這裡用一個普通物件 { value: 0 } 模擬 ref，方便在書裡執行。（真正的 ref 在 Console 印出來會顯示成 RefImpl {…}，裡面有更多東西，但值一樣放在 value。）

      • console.log(count) 印出的是整個盒子，不是 0。
      • count + 1 是「物件加 1」，得到奇怪的字串，不是 1。
      • count++ 想把 count 換成新的值，但 count 是 const，直接出錯。
      陷阱

      在 setup 裡讀或改 ref，一定要寫 .value。看到 [object Object]、RefImpl，或對 const 指定的錯誤，先檢查是不是漏了 .value。反過來，在模板裡多寫了 {{ count.value }} 也能顯示，但沒必要，大家都不這樣寫。

      9.4 ref 裡放物件和陣列

      ref 裡可以放任何東西，包括第 6 章的物件和陣列。改它們裡面的內容，畫面一樣會更新：

      改物件的屬性
      <div id="app">
    <p>{{ record.item }}：{{ record.amount }} 元</p>
    <button @click="addEgg">加一顆蛋</button>
</div>

<script>
    const { createApp, ref } = Vue;
    createApp({
        setup() {
            const record = ref({ item: "蛋餅", amount: 35 });
            const addEgg = () => {
                record.value.item = "加蛋蛋餅";
                record.value.amount += 10;
            };
            return { record, addEgg };
        }
    }).mount("#app");
</script>
      畫面

      record.value 是那個物件，record.value.amount 是它的金額。改了之後畫面就更新。

      陣列 push
      <div id="app">
    <p>共 {{ records.length }} 筆，最後一筆是 {{ records[records.length - 1] }}</p>
    <button @click="addLunch">記一筆午餐</button>
</div>

<script>
    const { createApp, ref } = Vue;
    createApp({
        setup() {
            const records = ref(["早餐"]);
            const addLunch = () => {
                records.value.push("午餐");
            };
            return { records, addLunch };
        }
    }).mount("#app");
</script>
      畫面

      records.value.push("午餐")：先 .value 拿出陣列，再 push。陣列的長度、最後一筆都自動更新了。pop、records.value[0] = "…" 這些改法也一樣會更新畫面。

      整個換掉也可以

      因為 records 是 const，我們不能寫 records = […]。但可以把盒子裡的東西整個換掉：

      整個換掉
      <div id="app">
    <p>共 {{ records.length }} 筆</p>
    <button @click="clear">清空</button>
</div>

<script>
    const { createApp, ref } = Vue;

      9.6 用 ref 改寫記帳程式

      用這一章學的東西，把第 7 章的記帳程式改寫一部分（列表要等第 11 章的 v-for，這裡先只顯示筆數和合計）。注意程式裡完全沒有更新畫面的程式碼：

      記帳：只管資料
      <div id="app">
    <p>共 {{ records.length }} 筆，合計 {{ total() }} 元</p>
    <button @click="addBreakfast">記一筆早餐 60 元</button>
    <button @click="addLunch">記一筆午餐 120 元</button>
    <button @click="clear">清空</button>

<script>

        setup() {

            const addBreakfast = () => {

</script>

      重點

      用 Vue 寫程式的思考方式：先想「資料長什麼樣子」，再寫「畫面怎麼顯示這些資料」，最後寫「使用者做什麼時，資料要怎麼改」。畫面更新交給 Vue。

      9.7 本章整理

      • 普通變數 return 給模板後，再怎麼改畫面都不會變。
      • ref(初始值) 建立響應式資料：值放在 .value，改 .value 時 Vue 會自動更新用到它的畫面。記得從 Vue 拿出 ref：const { createApp, ref } = Vue;。
      • JavaScript 裡要寫 .value，模板裡不用。漏了 .value 常見的症狀：[object Object]、RefImpl、對 const 指定的錯誤。
      • ref 裡的物件、陣列：改屬性、push、pop、整個換掉（x.value = …），畫面都會更新。
      • reactive 也是響應式資料，不用 .value 但有陷阱。本書一律用 ref。
      • Vue 的思考方式：資料 → 畫面怎麼顯示 → 使用者操作時怎麼改資料。

      10.1 v-bind：用資料決定屬性

      {{ }} 不能寫在屬性裡。想讓 <img> 的 src 來自資料，要用 v-bind：

      用資料決定屬性
      <div id="app">
    <img v-bind:src="logo" v-bind:alt="name" width="60">
    <p><a :href="url" target="_blank">{{ name }} 官網</a></p>
</div>

<script>
    const { createApp, ref } = Vue;
    createApp({
        setup() {
            const name = ref("Vue");
            const logo = ref("img/note.svg");
            const url = ref("https://vuejs.org/");
            return { name, logo, url };
        }
    }).mount("#app");
</script>
      畫面

      拆開 v-bind:src="logo"：

      部分意思
      v-bindVue 的指令：「把這個屬性綁定到資料」
      :src要綁的是哪個屬性
      "logo"引號裡是 JavaScript 運算式，不是字串。這裡是 logo 這個資料的值

      v-bind 太常用了，所以可以省略成只寫一個冒號：:href="url" 就是 v-bind:href="url"。大家幾乎都用簡寫，本書接下來也是。

      有沒有冒號，意思完全不同。src="logo" 沒有冒號，是一般的 HTML 屬性，值就是「logo」這四個字母；:src="logo" 有冒號，引號裡是 JavaScript，值是 logo 這個資料。忘了冒號，圖片就會去找一個叫 logo 的檔案。

      引號裡是 JavaScript

      屬性裡的運算式

    <button :disabled="amount <= 0">送出</button>
    <p>金額：{{ amount }}</p>
    <button @click="amount += 10">加 10 元</button>
</div>

<script>
    const { createApp, ref } = Vue;
    createApp({
        setup() {
            const example = ref("早餐");

            return { example, amount };

    }).mount("#app");
</script>

      10.2 綁定 class 和 style

      依照資料切換樣式，是 v-bind 最常見的用途。:class 可以給一個物件：key 是 class 名稱，值是 true 就加上、false 就不加。

      依照資料切換 class
      <style>
    .over { color: #e53935; font-weight: bold; }
</style>
<div id="app">
    <p :class="{ over: total > budget }">本月花了 {{ total }} 元（預算 {{ budget }}）</p>
    <button @click="total += 500">再花 500 元</button>
</div>

<script>
    const { createApp, ref } = Vue;
    createApp({
        setup() {
            const total = ref(4800);
            const budget = ref(5000);
            return { total, budget };
        }
    }).mount("#app");
</script>
      畫面

      { over: total > budget } 一開始是 { over: false }，所以沒有 class。按一下按鈕，總額變 5300，超過預算，運算式變成 { over: true }，Vue 就替段落加上 over，文字變紅。這就是第 7 章 classList.add / remove 做的事，但現在你只要描述「什麼條件下要有這個 class」，加和拿掉都交給 Vue。

      和一般 class 一起用

      :class 可以和一般的 class 同時存在，Vue 會把它們合在一起：

      class 合併

    .paid { color: #888; text-decoration: line-through; }
    .big { font-weight: bold; }
</style>
<div id="app">

      結果是 class="row paid big"。物件裡可以放很多組，每組各自判斷。

      綁定 style

      :style 也接受物件，key 是 CSS 屬性（寫成第 7 章的 camelCase），值是要設的值。適合「值是算出來的」樣式，例如進度條：

      預算進度條
      <style>
    .bar { width: 240px; height: 16px; background: #eee; }
    .fill { height: 100%; background: #2e7d32; }
</style>
<div id="app">
    <div class="bar">
        <div class="fill" :style="{ width: percent + '%' }"></div>
    </div>
    <p>已用 {{ percent }}%</p>
    <button @click="percent = Math.min(100, percent + 20)">花錢</button>
</div>

<script>
    const { createApp, ref } = Vue;
    createApp({
        setup() {
            const percent = ref(30);
            return { percent };
        }
    }).mount("#app");
</script>
      畫面

      { width: percent + '%' }：percent 是 30 時得到 { width: "30%" }。注意 '%' 要用引號，因為它是字串；整段屬性已經用雙引號包住了，所以裡面改用單引號。Math.min(100, …) 取兩個數裡比較小的那個，讓進度最多到 100。

      重點

      :class="{ 名稱: 條件 }" 依條件加上或拿掉 class；:style="{ 屬性: 值 }" 設定算出來的樣式。能用 class 解決的，優先用 class。

      10.3 v-on：處理事件

      第 9 章已經用過 @click。它是 v-on:click 的簡寫，用來監聽事件，等於第 7 章的 addEventListener：

      完整寫法簡寫
      v-on:click="add"@click="add"
      v-on:input="onInput"@input="onInput"

      引號裡有三種常見寫法：

      三種寫法
      <div id="app">
    <p>{{ count }}</p>
    <button @click="add">寫函式名稱</button>
    <button @click="addMany(10)">呼叫並傳參數</button>
    <button @click="count = 0">直接寫一行程式</button>
</div>

<script>
    const { createApp, ref } = Vue;
    createApp({
        setup() {
            const count = ref(0);
            const add = () => {
                count.value++;
            };
            const addMany = (n) => {
                count.value += n;
            };
            return { count, add, addMany };
        }
    }).mount("#app");
</script>
      畫面
      寫法什麼時候用
      @click="add"只寫函式名稱，不加括號。點擊時 Vue 會呼叫 add
      @click="addMany(10)"需要傳參數時，寫成呼叫的樣子。不會在畫面一出現就執行，而是點擊時才執行
      @click="count = 0"很短的程式可以直接寫。模板裡不用寫 .value
      陷阱

      第 5 章說「把函式交出去時不要加括號」，但 @click="addMany(10)" 卻加了括號，這不是矛盾嗎？差別在於：@click 引號裡的東西，Vue 會包成一個函式，點擊時才執行，所以寫成呼叫的樣子是安全的。第 7 章的 addEventListener("click", addMany(10)) 才會立刻執行，那是純 JavaScript。

      傳參數最常見的用途：同一個函式處理不同的資料。例如刪除按鈕要傳「刪哪一筆」的 id，第 11 章做列表時會一直用到。

      : 和 @ 可以在同一個元素上一起用：<button :disabled="amount <= 0" @click="save">。

      10.4 讀取事件的資訊

      瀏覽器呼叫事件函式時，會傳進一個事件物件，裡面有這次事件的資訊。用 @click="函式名稱"（不加括號）時，函式的第一個參數就是它：

      從事件物件讀輸入框
      <div id="app">
    <input @input="onInput" placeholder="打字試試">
    <p>你打了：{{ text }}（{{ text.length }} 個字）</p>
</div>

<script>
    const { createApp, ref } = Vue;
    createApp({
        setup() {
            const text = ref("");
            const onInput = (event) => {
                text.value = event.target.value;
            };
            return { text, onInput };
        }
    }).mount("#app");
</script>
      畫面

      event.target 是「發生事件的那個元素」，這裡就是輸入框，所以 event.target.value 是輸入框目前的內容。每打一個字觸發一次 input 事件，就把內容存進 text，畫面跟著更新。

      如果又要傳參數、又要事件物件，用 Vue 提供的特殊名稱 $event：@input="onInput($event, 'item')"。

      這種「輸入框的內容 ↔ 資料」雙向同步太常見了，Vue 有專門的 v-model 一行搞定，第 12 章會教。這裡先了解它背後是怎麼運作的。

      10.5 事件修飾符

      Vue 可以在事件名稱後面加上修飾符（modifier），處理常見的需求。最常用的是按鍵：

      按 Enter 新增
      <div id="app">
    <input @keyup.enter="add" @input="onInput" :value="item" placeholder="打完按 Enter">
    <p>已新增 {{ count }} 筆，最後一筆：{{ last }}</p>
</div>

<script>
    const { createApp, ref } = Vue;
    createApp({
        setup() {
            const item = ref("");
            const last = ref("");
            const count = ref(0);
            const onInput = (event) => {
                item.value = event.target.value;
            };
            const add = () => {
                if (item.value === "") return;
                last.value = item.value;
                count.value++;
                item.value = "";
            };
            return { item, last, count, onInput, add };
        }
    }).mount("#app");
</script>
      畫面

      @keyup.enter="add"：放開按鍵（keyup）時，只有那個鍵是 Enter 才呼叫 add。不用自己寫「判斷是不是 Enter」的程式。:value="item" 讓輸入框顯示 item 的值，新增後把 item 清成空字串，輸入框也跟著清空。（if (item.value === "") return; 是把第 5 章的提早 return 寫成一行，if 後面只有一行時可以省略大括號。）

      修飾符意思
      @keyup.enter只在按 Enter 時觸發。另外還有 .esc、.space 等
      @submit.prevent阻止瀏覽器預設的行為。表單送出時瀏覽器預設會重新載入整頁，.prevent 可以擋掉，改由你的函式處理
      @click.once只觸發第一次

      10.6 指令總整理

      v-bind、v-on 這種寫在元素上、以 v- 開頭的特殊屬性，叫做 Vue 的指令（directive）。它們的引號裡都是 JavaScript 運算式。下一章的 v-if、v-for，第 12 章的 v-model，也都是指令。

      寫法簡寫做什麼哪裡教
      {{ 運算式 }}把值放進元素內容第 8 章
      v-bind:屬性="…":屬性="…"把值放進屬性這一章
      v-on:事件="…"@事件="…"事件發生時執行這一章
      v-if、v-show、v-for條件顯示、重複顯示第 11 章
      v-model輸入框和資料雙向同步第 12 章
      重點

      看到 : 開頭的屬性，引號裡是 JavaScript；看到 @ 開頭的屬性，是事件。沒有符號的一般屬性，引號裡就只是字串。

      10.7 本章整理

      • :屬性="運算式"（v-bind 的簡寫）讓屬性的值來自資料，資料變了屬性也會變。沒有冒號就只是字串。
      • 布林屬性（disabled、checked）綁 true 加上、綁 false 拿掉。
      • :class="{ 名稱: 條件 }" 依條件加上或拿掉 class，可以和一般 class 一起用。:style="{ camelCase屬性: 值 }" 設定算出來的樣式。
      • @事件="…"（v-on 的簡寫）：可以寫函式名稱、帶參數的呼叫（點擊時才執行）、或一行程式。
      • 只寫函式名稱時，函式會收到事件物件；event.target.value 是輸入框的內容。需要同時傳參數時用 $event。
      • 修飾符：@keyup.enter 只在按 Enter 時觸發，@submit.prevent 擋掉表單送出的重新載入。
      • v- 開頭的特殊屬性叫指令，引號裡都是 JavaScript。

      這一章學模板裡的「判斷」和「迴圈」：條件成立才顯示某一塊，以及資料有幾筆就重複顯示幾次。念完你會 v-if、v-else、v-show、v-for 和 key，並且終於能把記帳資料顯示成完整的列表，還能刪除其中一筆。

      11.1 v-if：條件成立才顯示

      沒有資料時顯示提示
      <div id="app">
    <p v-if="records.length === 0">還沒有任何記帳</p>
    <p v-else>共 {{ records.length }} 筆</p>
    <button @click="records.push('早餐')">記一筆</button>
</div>

<script>
    const { createApp, ref } = Vue;
    createApp({
        setup() {
            const records = ref([]);
            return { records };
        }
    }).mount("#app");
</script>
      畫面

      v-if="條件"：條件是 truthy（第 4 章）才顯示這個元素，否則整個元素不存在。v-else 緊接在後面，條件不成立時顯示它。這就是第 4 章的 if…else，只是寫在模板裡。

      一開始沒有資料，只顯示「還沒有任何記帳」；按一下按鈕，條件變成不成立，第一段消失、換成「共 1 筆」。兩段永遠只會出現其中一段。

      v-else-if

      好幾種情況
      <div id="app">
    <p v-if="total > budget">超支了！</p>
    <p v-else-if="total > budget * 0.8">快用完了</p>
    <p v-else>還很充裕</p>
    <p>已花 {{ total }} / {{ budget }}</p>
    <button @click="total += 1000">花 1000 元</button>
</div>

<script>
    const { createApp, ref } = Vue;
    createApp({
        setup() {
            const total = ref(2500);
            const budget = ref(5000);
            return { total, budget };
        }
    }).mount("#app");
</script>
      畫面

      跟第 4 章的 else if 一樣，由上往下檢查，第一個成立的才顯示。按幾次按鈕，看提示怎麼變。

      陷阱

      v-else 和 v-else-if 必須緊接在 v-if（或 v-else-if）元素的後面，中間不能夾其他元素，否則 Vue 找不到它跟哪個 v-if 是一組，會在 Console 出現警告。

      一次控制好幾個元素

      想用一個條件控制好幾個元素，又不想多包一層 div，可以用 <template> 包起來。<template> 本身不會出現在畫面上，只是一個看不見的容器：

      HTML
      <template v-if="isOver">
    <h3>超支警告</h3>
    <p>本月已超過預算，請注意。</p>
</template>

      按「切換」，兩段都消失了，看起來一樣。但如果打開開發者工具的 Elements 看，會發現差別：

      v-ifv-show
      條件不成立時元素整個被移除，Elements 裡找不到元素還在，只是加上 style="display: none;"（第 2 章 2.7 節）
      切換的成本每次都要建立或移除元素，比較重只改一個 CSS，很輕
      能不能接 v-else可以不行
      適合條件很少改變，或不想讓它存在（例如沒權限看的區塊）要頻繁切換，例如展開／收合的選單

      初學時不用太在意效能差別，大部分情況用 v-if 就好。知道兩者的差別，看到 v-show 時才不會疑惑。

      11.3 v-for：資料有幾筆就顯示幾次

      第 7 章用 createElement 和迴圈一筆一筆建立 li。在 Vue 裡，只要一行：

      顯示清單
      <div id="app">
    <ul>
        <li v-for="item in items" :key="item">{{ item }}</li>
    </ul>
</div>

<script>
    const { createApp, ref } = Vue;
    createApp({
        setup() {
            const items = ref(["早餐", "午餐", "晚餐"]);
            return { items };
        }
    }).mount("#app");
</script>
      畫面

      v-for 寫在要重複的那個元素上。拆開 v-for="item in items"：

      部分意思
      items要走過的陣列（setup return 出來的資料）
      in「在…裡面」
      item每一圈拿到的那一個元素，名字自己取。只能在這個元素和它裡面使用

      它就像第 6 章的 for (const item of items)：陣列有三個元素，li 就出現三次，每次的 item 各是一個元素。:key 下一節講。

      同時拿索引

      加上編號
      <div id="app">
    <p v-for="(item, index) in items" :key="item">{{ index + 1 }}. {{ item }}</p>
</div>

<script>
    const { createApp, ref } = Vue;
    createApp({
        setup() {
            const items = ref(["早餐", "午餐", "晚餐"]);
            return { items };
        }
    }).mount("#app");
</script>
      畫面

      寫成 (item, index) in items，第二個名字會拿到索引（從 0 開始），跟第 6 章 forEach((item, index) => …) 的順序一樣。

      物件陣列

      真正的記帳資料是物件陣列（第 6 章 6.5 節），item 拿到的就是一個物件，用點讀它的屬性：

      記帳列表
      <style>
    .row { display: flex; justify-content: space-between; max-width: 280px; padding: 4px 0; border-bottom: 1px solid #ddd; }
</style>
<div id="app">
    <div class="row" v-for="r in records" :key="r.id">
        <span>{{ r.item }}</span>
        <span>{{ r.amount }} 元</span>
    </div>
</div>

<script>
    const { createApp, ref } = Vue;
    createApp({
        setup() {
            const records = ref([
                { id: 1, item: "早餐", amount: 60 },
                { id: 2, item: "捷運", amount: 35 },
                { id: 3, item: "午餐", amount: 120 }
            ]);
            return { records };
        }
    }).mount("#app");
</script>
      畫面

      對照第 7 章的 render()：那裡要清空、createElement、設定 textContent、append，這裡只要把「一筆長什麼樣子」寫成 HTML，前面加上 v-for。而且 records 是 ref，之後新增、刪除，列表都會自動更新。

      重點

      v-for="x in 陣列" 寫在要重複的元素上，陣列有幾筆就產生幾個。要索引就寫 (x, i) in 陣列。

      11.4 key：讓 Vue 認得每一筆

      :key="r.id" 是在告訴 Vue：「每一筆用 r.id 來辨認」。為什麼需要它？

      資料變動時（新增、刪除、排序），Vue 要決定畫面上哪些元素可以留著、哪些要新建、哪些要移除。如果每一筆都有一個不重複、不會變的 key，Vue 就能準確地對上「這個元素是哪一筆資料」，只動該動的部分。沒有 key，Vue 只能照位置猜，在某些情況下會把 A 筆的狀態（例如輸入框裡打到一半的字）留給 B 筆，造成很難找的錯誤。

      拿什麼當 key好不好原因
      資料的 id最好每筆都不一樣，而且不會因為新增刪除而改變
      字串本身（:key="item"）只有內容保證不重複時可以11.3 節的範例三個字串都不同才這樣寫；如果有兩筆「早餐」就會重複
      索引（:key="index"）盡量不要刪掉第一筆，後面每一筆的索引都會變，key 等於沒用

      這也是第 6 章說「每筆資料要有一個不重複的 id」的原因。

      陷阱

      key 一定要用 :key（有冒號）。寫成 key="r.id" 沒有冒號，每一筆的 key 都是「r.id」這四個字，全部重複。key 重複時 Vue 會在 Console 出現 Duplicate keys 的警告。

      重點

      v-for 一律加上 :key，用資料裡不重複的 id。

      11.5 新增和刪除

      把第 10 章的事件和這一章的 v-for 組起來：每一筆旁邊放一個刪除按鈕，點了就刪掉那一筆。

      可以新增和刪除的記帳列表
      <style>
    .row { display: flex; gap: 8px; align-items: center; max-width: 300px; padding: 4px 0; }
    .row span:first-child { flex: 1; }
</style>
<div id="app">
    <p v-if="records.length === 0">還沒有任何記帳</p>
    <div class="row" v-for="r in records" :key="r.id">
        <span>{{ r.item }}</span>
        <span>{{ r.amount }} 元</span>
        <button @click="remove(r.id)">刪除</button>
    </div>
    <p>
        <button @click="add('早餐', 60)">記早餐</button>
        <button @click="add('午餐', 120)">記午餐</button>
    </p>
</div>

<script>
    const { createApp, ref } = Vue;
    createApp({
        setup() {
            const records = ref([
                { id: 1, item: "早餐", amount: 60 }
            ]);
            let nextId = 2;
            const add = (item, amount) => {
                records.value.push({ id: nextId, item, amount });
                nextId++;
            };
            const remove = (id) => {
                records.value = records.value.filter((r) => r.id !== id);
            };
            return { records, add, remove };
        }
    }).mount("#app");
</script>
      畫面

      重點在刪除按鈕：

      • @click="remove(r.id)"：每一筆的按鈕都呼叫同一個 remove，但傳進去的是自己那一筆的 id（第 10 章的傳參數）。r 在 v-for 的元素裡面都能用。
      • remove 用第 6 章的 filter 留下「id 不是這一筆」的資料，再放回 records.value（第 9 章 9.4 節）。
      • 新增時 { id: nextId, item, amount } 用了第 8 章的物件簡寫，等於 { id: nextId, item: item, amount: amount }。nextId 確保每筆的 id 都不一樣。

      刪到一筆不剩時，v-if 的「還沒有任何記帳」就會出現。整段程式裡，依然沒有任何一行在「更新畫面」。

      這裡刻意加了兩筆一模一樣的「早餐」：它們內容相同，但 id 不同，所以刪除時不會刪錯。這就是 key 和 id 的用處。

      11.6 v-for 搭配條件：只顯示部分資料

      常見需求：只顯示某一類的資料。直覺會想把 v-if 和 v-for 寫在同一個元素上，但不要這樣做：

      HTML
      <!-- 不要這樣寫 -->
<li v-for="r in records" v-if="r.type === '餐飲'" :key="r.id">{{ r.item }}</li>

      在 Vue 3 裡，同一個元素上 v-if 會先執行，那時 r 還不存在，會出錯。正確的做法是先在 JavaScript 裡用 filter 算出要顯示的資料，再交給 v-for：

      依分類篩選
      <div id="app">
    <p>
        <button @click="type = '全部'">全部</button>
        <button @click="type = '餐飲'">餐飲</button>
        <button @click="type = '交通'">交通</button>
        目前：{{ type }}
    </p>
    <ul>
        <li v-for="r in shown()" :key="r.id">{{ r.item }}（{{ r.type }}）</li>
    </ul>
</div>

<script>
    const { createApp, ref } = Vue;
    createApp({
        setup() {
            const records = ref([
                { id: 1, item: "早餐", type: "餐飲" },
                { id: 2, item: "捷運", type: "交通" },
                { id: 3, item: "午餐", type: "餐飲" }
            ]);
            const type = ref("全部");
            const shown = () => {
                if (type.value === "全部") return records.value;
                return records.value.filter((r) => r.type === type.value);
            };
            return { type, shown };
        }
    }).mount("#app");
</script>
      畫面

      shown() 依照目前選的分類回傳要顯示的陣列，v-for 只負責把它畫出來。點分類按鈕改變 type，Vue 重畫時重新呼叫 shown()，列表就跟著變。第 13 章會把 shown 改寫成更適合的 computed。

      如果只是想在某些項目上多顯示一點東西（而不是整筆不顯示），可以把 v-if 寫在 v-for 元素裡面的子元素上，那時 r 已經存在了，沒有問題：

      HTML
      <li v-for="r in records" :key="r.id">
    {{ r.item }}
    <strong v-if="r.amount >= 100">大筆</strong>
</li>
      陷阱

      不要把 v-if 和 v-for 放在同一個元素上。要篩選資料，先在 JavaScript 用 filter；要在某幾筆多顯示東西，把 v-if 放在裡面的子元素。

      11.7 本章整理

      • v-if="條件" 成立才顯示，不成立時元素整個不存在。v-else-if、v-else 要緊接在後面。<template> 可以一次包住好幾個元素。
      • v-show 不成立時只是 display: none，元素還在。頻繁切換用 v-show，其他用 v-if。
      • v-for="x in 陣列" 寫在要重複的元素上；(x, i) in 陣列 同時拿索引。物件陣列用 x.屬性 讀值。
      • v-for 一律加 :key，用不重複、不會變的 id。不要用索引。
      • 刪除一筆：按鈕傳自己的 id，records.value = records.value.filter((r) => r.id !== id)。
      • 不要把 v-if 和 v-for 寫在同一個元素上。篩選先在 JavaScript 用 filter。
